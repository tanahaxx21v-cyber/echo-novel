# ECHO 第4話「値段のついた記憶」

　ソルの記録は上層が消した。しかし消えたのは記録だけかもしれなかった。

　記憶は分離できる。分離された記憶は売れる。中層の記憶マーケットはそういう場所だ——カインはそれをエコーの古いログで読んでいた。

　上層へ行く前に、確かめておく場所があった。

　翌朝、カインはセラに言った。

「記憶マーケットに行く。来い」

「……一緒に行っていいんですか」

　セラが少し目を見開いた。「来い」と言われることを予期していなかった顔だった。

「ソルのことで、確かめることがある」

---

　記憶マーケットは中層の北回廊、三番扉の奥にある。表向きは「情報取引所」という名前だが、実際に売買されているのは分離された記憶だ。

　三番扉を開けると、音が薄くなった。外の通路の人の気配が、ここには届かない。においもなかった。清潔というより、何かが抜けた空気だった。

　値段表が入口の板に出ていた。

```
[一般記憶（事実・知識）：12〜40ゴール]
[感情記憶：250〜800ゴール]
[子どもの記憶（感情）：1,200ゴール〜]
```

　セラが立ち止まった。

「子どもの記憶が……一番高いんですか」

「感情が純粋なほど値が上がる。子どもの記憶は混じりけがない」

　セラは何も言わなかった。それだけ聞ければ十分だった、という顔だった。

---

　奥の照会端末に、出品中の記憶一覧が並んでいた。年代・年齢・感情種別で絞り込める。カインは条件を入れた。MemOris区。六歳。六年前。感情記憶。

　一件ヒットした。

```
[ソル / 2389年生 / MemOris区 / 6歳時感情記憶 / 出品者：非公開 / 内容：非公開 / 価格：要問い合わせ]
```

　セラが息を止めた。

　端末を見ている目が動かなくなった。

　連れてくるべきではなかった。そう考えた。答えは出なかった。

　カインは端末から手を離した。

「出品者は非公開だ。内容も見られない。誰が売ったかは分からない」

「ソルの記憶も……」

　声が止まった。セラは口を閉じた。

「あるいは、売られようとしている」

　セラはしばらく端末を見た。[ソル / 6歳 / 感情記憶]という文字だけがある。その先は何もない。それでも十分な重さがあった。

「ここにあるかもしれない」——その言葉を、セラは言わなかった。

　カインはそれを見ていた。

---

　施設に戻ったのは夕方だった。

　廊下でミラが出てきた。

「どうだった」

「記憶が売れる。子どもの感情記憶が高かった」

　ミラは少し間を置いた。それから「そうか」と言って、手元のファイルをひとまとめにした。素早く閉じた。表紙に「K」の文字が見えた。閉じた理由は言わなかった。カインは何も聞かなかった。

---

　通路の角で、リンが壁際に立っていた。手に小さな包みを持っている。

　リンはカインを見て、少し間を置いた。それから包みを差し出した。

「……食べる？」

　奥からジンが出てきた。「少ないけどな」と言いながら、リンの手元に何かを足した。

「……うん」とリンが受け取った。カインを知っている顔でジンを見た。

　カインは包みを受け取った。何も言わなかった。施設に帰ってきた、という感覚だった。

---

　夜、廊下を歩いていると、セラが部屋の前に立っていた。壁に手をついて、うつむいている。配管の音が低く続いていた。

　カインは立ち止まった。

　なぜまだここにいるのか、という問いが浮かんだ。帰す理由も置いておく理由も、どちらも言葉にならない。この数日で同じ問いが何度か浮かんで、そのたびに答えが出なかった。

　声をかけようとして、やめた。

　廊下の奥へ歩いた。

　端末の表示が頭の端に残っていた。出品者は非公開だった。ソルの感情記憶を、誰かが売った。誰が、なぜ。その問いに答えは出なかった。

---

```
【日記の断片】

感情記憶が最も高値だった。
喜びと痛みは同じ価格がついた。
私はそれを聞いて、この世界が何を間違えたかを理解した。
感情とは売れるものではない。感情とは、経験の積み重ねだ。
それを取り出した瞬間、その人間は少し死ぬ。
```
