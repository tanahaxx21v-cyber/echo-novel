# ECHO 第1話「それでも朝は来る」

　昨日まで、この老人は自分の名前を言えた。

　カインは三叉路の前で足を止めた。

　老人がそこに立っていた。七十代か、それ以上か。バンドのない腕をだらりと下げて、どちらの通路も見ていない。立っているというより、そこに置かれているという感じだった。

　目が虚ろだった。何かを見ているようで、何も見ていない。三叉路のどちらへ行くかを決められないのではなかった。どちらが「道」であるかを、もう知らないのだ。

　一週間前に一度だけ言葉を交わしたことがある。「水を分けてくれないか」と言われて、持っていた一本を渡した。老人は「ありがとう、カインさん」と言った。声ははっきりしていた。そこに人間がいた。

　今朝の目は、別のものだった。

　白化だった。

　カインは老人の右腕を取った。抵抗はなかった。腕は軽かった。足が動いた。記憶が消えても、体が動くことを覚えている。全てが消えても、動けてしまう。それでも体は、生き続けていた。

　施設の入口まで連れて行き、中にいた女に任せた。

「また一人か」と女は言った。怒るわけでも嘆くわけでもなく、確認する声だった。

　カインは頷かずに出てきた。

　光は、朝でも変わらない。天井から垂れ下がる誘導灯が点滅を繰り返す。消えていないことを告げるだけの光。地下三百メートル——ここへ地上の太陽が届いたことは一度もない。それでも時刻は六時二十分で、どこかの施設から子どもの声が聞こえた。

　カインは歩いた。灰色のジャケットのポケットに手を入れたまま、古い通路を進む。コンクリートの床に、誰かが書いた文字があった。消されかけて、また書かれた跡がある。名前だったかもしれない。今はもう判別できない。

　施設に戻るまでの間、頭の中で名前を数えた。ジン。ミラ。オルト。リン。今朝の老人の名前は、もう知らない。

---

　施設に戻ったのは七時を過ぎた頃だった。

　ドアを開けると、ジンがいた。

　入口の柱に背中を預けて、古い上着の袖口をいじっている。大柄な体が、この狭い廊下だと壁に見えた。テーブルの上に包みが置いてあった。

「遅かったな」

　それだけ言って、テーブルの包みをカインの方へ押した。

　乾燥させた保存食が二つ。水のボトルが一本。

　カインは受け取った。何も言わなかった。ジンも何も言わなかった。受け取ることで十分だった。

　ジンはもう自分の部屋の方向へ歩いていた。

「飯食ったか？」

「今食う」

「そうか」

　一歩歩いて、ジンは振り返らずに言った。

「肉みたいな味がするやつ入れといた」

　カインは何も言わなかった。包みを開けると、いつもより少し色の濃い保存食が入っていた。

　味は、あまり変わらなかった。それでもジンが選んで持ってきたものだった。

---

　八時になると、ミラが施設の廊下に出てきた。

　薄い茶色のシャツに、くたびれた厚手のカーディガン。五十三歳の体が疲れを染み込ませているような立ち方をしているが、目だけが鋭かった。

「今日も、全員いるか」

　問いではなかった。確認だった。

　廊下にいた三人が顔を上げる。カイン、それからオルト、それからリン。

　オルトは椅子に腰かけたまま壁の一点を見ていた。六十七歳、白い髪が朝の誘導灯を反射している。話しかけると、答えが途中で止まることがある。

　リンは廊下の端に立って、袖の先端を両手で掴んでいた。十四歳。目だけは何かを見ていた。

「ジンは？」

「部屋にいる」とカインは答えた。

　ミラは小さく頷いた。安堵というより、確認が完了した顔だった。そのまま廊下の奥へ消えた。

　カインは、その確認が何年も前からあることを知っている。なぜミラがそれをするのかを、ミラは一度も説明しなかった。ただ、毎朝「全員いるか」と確かめて、全員いることを知ると、また自分の仕事に戻る。

　カインも、毎朝確かめる。廊下に誰がいるかを。誰がいなくなっていないかを。それをカインも、説明したことはない。

　オルトが口を開いた。

「……あの、カイン。今日は何日でしたか」

「七月の十四日だ」

「そうか。七月か」

　オルトはしばらく宙を見た。白い眉が寄る。

「……七月に、何かあったような気がするのだが、何だったか」

　カインは答えなかった。外から補填しても、それはオルトの記憶ではない。

「……まあ……」

　オルトはまた壁に目を戻した。リンが廊下の端から、無言でどこかへ歩いていった。

---

　午後、ジンがカインの隣に腰を下ろした。

「何読んでるんだ」

「エコーのログ」

「また難しいもん読んでるな」

　笑って、腕を組んだ。カインは読み続けた。

　しばらく二人で黙っていた。ジンが誘導灯を見上げて、言った。

「昔は、本物の光があったらしいぞ。地上の」

「知ってる」

「見たいとは思わないか」

「思ったことない」

　ジンは少し黙った。

「俺は思うけどな。見たい」

　カインは資料から目を上げた。ジンが空を見るような目で天井を見ていた。天井には光源しかない。それでも、その目には何か別のものが映っていた。

「お前も少しは思えよ」

　ジンが笑った。低い笑い声だった。カインは何も言わなかった。それでもジンは、もう一秒だけ笑っていた。それから「飯の時間だ」と言って立ち上がり、去った。

　カインは資料を閉じた。誰かが記録し続けている。なぜ記録が存在するのか。誰が管理しているのか。その問いを、カインはずっと手放せなかった。

---

　夜になった。

　カインは外へ出た。

　ダーク4番区の北端、古いターミナルがある。五年前に誰かが設置したまま撤去されない。画面の右端に亀裂が入っているが、機能している。

　[ECHO] という文字が、薄い緑のフォントで画面の左上に常時表示されている。白化の発生件数。断片的な数字が、画面を流れていく。

　画面が更新された。

```
[ECHO：本日の白化発生件数：14件]
```

　14件。今日だけで、14人分の何かが消えた。今朝の老人が含まれているかどうか、分からない。バンドのない腕が、数字として数えられているのか。誰かが数えている。誰かが記録している。なぜ、このシステムが存在するのか。

　立ち去ろうとした。

　その瞬間、画面が変わった。

```
[ECHO：——]
```

　一秒あるかないかの間、何もなかった。

　「14件」も消えていた。「ECHO」の表記も消えていた。画面全体が、緑のフォントの残像だけを残して、空白になった。

　次の瞬間には戻っていた。

```
[ECHO：本日の白化発生件数：14件]
```

　カインは壁から背中を離して歩き始めた。通路を数歩歩いてから気がついた——ターミナルが一瞬ブランクになった。カインはその変化を見ていなかった。見ていたはずなのに、見ていなかった。

　ターミナルは、誰もいない通路で、静かに同じ数字を吐き続けていた。

---

```
【日記の断片】

私はこの記録を、誰に読まれるためでもなく書き始めた。
真実は、公式記録の中に存在しない。
だからこそ、私は書く。
```
