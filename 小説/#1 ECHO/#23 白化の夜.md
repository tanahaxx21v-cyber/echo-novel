# ECHO 第23話「白化の夜」

　翌日の朝、カインはログを整理していた。

　昨日書いた記録を見直した。「セラが宣言した」「アンが「はい」と答えた」「ミラが明日話すと言った」——その「明日」が今日だった。カインは記録を閉じた。棚の上に置いた。施設の朝は静かだった。配管の音がした。誘導灯が点滅していた。昨日と同じ朝だった。同じ朝だが、今日は何かが動く日だった。

　カインは外に出た。

---

　エコーのアーカイブ塔の外部端末に来た。

　昨日ミラが「話があります」と言った。しかしその前に確認すべきことがあった——「K-001実験記録」がアーカイブに残っているかどうか。ミラに全てを聞く前に、自分で確認できることを確認しておく必要があった。

　セラがついてきていた。アンも。

　外部端末を通れた。フェールオープンで中に入った。

　アーカイブの内部は、白い棚が続いていた。物理的な棚ではなく、端末が並んでいた。検索フィールドがあった。「K-001」と入力した。

　結果が出た。

```
K-001実験記録 / 2375年〜2376年 / 分類：評議局総督府承認案件 / 公開制限：最高位
```

　存在した。

---

　アクセスコードが必要だった。通常は入れない。しかしフェールオープンが使えた——「記録にない者」は端末が「エラー」として通してしまう。カインが端末の前に立った。「センサー故障」と判定された。閲覧が開けた。

　セラが横に来た。アンが後ろに立った。三人でファイルの中に入った。アーカイブの内部は静かだった。外の音が聞こえなかった。白い壁と端末だけがあった。文書が画面に出る前の数秒、セラが少し息を整えているのがカインには分かった。

　文書が出た。

```
K-001実験報告書（2375年3月〜2376年8月）

目的：感情記憶の選択的制御と白化耐性の研究
被験体：K-001（Blanc・男性・誕生年2375年）
主要所見：感情記憶を全て除去した被験体は白化しない
理由：エコーが「奪う記憶がない」ため白化処理が起動しない
副作用：被験体に「記録する衝動」が残存（感情の代替）
実験終了理由：「倫理的問題」により中止
政治的承認者：評議局総督府（第7次会議・2375年3月）
```

　カインは文書を読んだ。読み返した。

　「Blanc・男性・誕生年2375年」。カインは2375年生まれだった。「感情記憶を全て除去した被験体は白化しない」——「最初の記憶がない」という自分の事実と重なった。「記録する衝動が残存」——毎晩ログを取り続けている自分の習慣と重なった。

　読み終えて、カインは端末から離れた。

　セラが少し離れた位置で待っていた。

「……K-001は、カインのことですか」

　カインは答えなかった。

　答えが出なかった——確認している段階だった。文書に書かれていることが事実なら、そうなる。「Blanc・男性・誕生年2375年」——カインは2375年生まれだった。「感情記憶を全て除去した」——最初の記憶がない、という自分の事実。「記録する衝動が残存」——毎晩ログを書き続ける習慣。全部が一致していた。一致していても、今日ここで決めることではなかった。ミラに聞く。それが今日の次だった。

---

　文書の様式を少し見た。

　ミラが以前「様式が統一されている」と言った記録があった——いや、カインが「研究チームの記録か」と思ったのだった。この文書の様式は確かに統一されていた。一定の書き方。一定の形式。ミラが横に来た。

「……この様式、見覚えがあります」

　ミラが呟いた。「これまでの日記の記録様式と——似ている。研究チームが書いた？」

　セラが「日記？」と言いかけた。

　ミラがすぐに「いえ、文書の形式の話です」と続けた。

　カインは何も言わなかった。

---

　アーカイブ塔の外に出た。

　三人で歩いた。誰も長い間、何も言わなかった。

　白化件数の起源について、ジンが以前「投票で決まったんだよ、白化」と言っていた。今日、その「投票」の前提が分かった。投票前の6週間、白化の「被害映像」が情報端末で繰り返し流されていた記録がアーカイブに残っていた。恐怖を最大化した後に投票させた。賛成68%——数字は「民主主義」として正しかった。しかし前提が操作されていた。「市民が選んだのではなく、市民に選ばせた」という構造だった。

　長い沈黙だった。三人が歩いている間、誰も言葉を出さなかった。

　カインは「誰が悪かったのか」を考えた。K-001実験を政治的に承認した評議局総督府。実験を実施した研究者。「辛い記憶を消してほしい」と投票した市民。恐怖を前置きした誰か。全部が繋がっていた。一人を指差すことができなかった。指差せないことが、一番重かった。

　「正しい手続きで生まれた結果は、正しいか」——答えが出なかった。ジンが「投票で決まった」と言った時、「誰かが悪い」という問いの答えは少し変わると思っていた。しかし今日分かったのは「投票そのものが操作されていた」という事実だった。「市民が決めた」という表面と「市民に決めさせた」という実態——その隙間に、全てがあった。

　セラが先を歩きながら一言だけ言った。

「……ソルを取り戻す方法があるなら、それを先に探します。誰が悪かったかは——後で考えます」

　カインは答えなかった。

　セラがそう言えるようになった——第22話の「私は私だ」という宣言から続く行動者として。今日の重さの中に一つ確かなものとして残った。

---

　施設に戻った。

　ミラが廊下に出てきた。

「カイン」

「ん」

「文書を見てきたか」

「ああ」

　ミラが少し間を置いた。

「……明日——いや、今日話します。今日の夜」

　カインはミラを見た。

「分かった」

　廊下が静かだった。

　「K-001実験の被験体」という文字がまだ頭の端にあった。自分のことかどうかを、ミラに確かめる。それが今日の夜だった。ミラが答える前の今この時間、答えが出ていない状態がまだ続いていた。

　カインはログを取り出して、今日の記録を書いた。「アーカイブに文書があった。内容は確認した。今夜ミラが話す」——それだけだった。

　その夜、ミラが「話します」と言って部屋に呼んだ。セラもいた。アンも壁際に立った。

　ミラが口を開く前の一秒——カインには何かが変わる前の静かさとして感じた。

「K-001は——カインか」

　カインが聞いた。

　ミラが答えなかった。

　一秒。二秒。

　ミラが目を逸らした。逸らしたまま、何も言わなかった。

　答えなかったことが——答えだった。

　カインは今夜の記録を書かなかった。書けなかった、ということではなかった。書く前に、少し止まっていた。「K-001実験の被験体」という言葉の前では、記録が追いつかなかった。今夜は止まったまま、朝を待った。

---

```
【日記の断片】

真実を知った日のことを、私は覚えている。
知ることは必ずしも救済ではない。
知ることは——責任の始まりだ。
知った者は、動かなければならない。
私はここに書くことで、動いた。
```
