# ECHO 第16話「データの中の名前」

　記憶アーカイブ塔の外部端末は、中層の境界から徒歩十五分の場所にある。

　ミラが地図を手書きで渡してきた。「中に入ることはできません。外部端末ならフェールオープンで通れるはずです」と言った。「何のデータが入っているか」と聞くと、「エコーの登録データです。市民の記憶バックアップ、記憶データの保管状況、各個人の登録年。Blancのデータが入っているかは分かりません」と答えた。入っているかどうかを確かめるしかなかった。

　カインとセラで向かった。アンが後ろについた。

　塔は高かった。エコロン内の建物の中でも、際立って高かった。外壁が白く、継ぎ目が見えないほど均一だった。白い壁に囲まれた、白い構造物だった。中に何が入っているのかは外から見えなかった。窓もなかった。見えるのは高さと白さだけで、それが「何かを保管している」という圧力を持っていた。

　外部端末は塔の側面に設置されていた。誰でも使えるように作られた端末ではなかった。専用のアクセスが必要で、通常はバンドの認証が要る。しかし端末の前に立てばすぐに分かった——読み取り機の前に腕を差し出した瞬間、カインは「センサー故障」という表示を目では確認できなかったが、外部端末のパネルが起動した。通れた。

---

　セラが「私もやってみます」と言って、メモリアを端末に近づけた。認証が通った。セラのバンドは正規のものだ。カインとセラ、それぞれの別々の経路で、端末の前に立った。

　端末を操作したのはカインだった。「名前、登録年、区画」のフィールドがあった。名前：ソル。登録年：2395年以降。区画：上層。入力した。

　セラが画面を見ていた。結果が出るまでの数秒、セラは動いていなかった。息をしているかどうかも、カインには分からなかった。

　結果が出た。

```
ソル / 記憶データ / 保管中 / 2395年〜
```

　セラが動かなくなった。

　一秒、二秒、三秒。動かなかった。

　画面には「保管中」という文字があった。データが存在する、という意味だった。ただそれだけだった。体がある、という意味ではなかった。生きている、という意味でもなかった。しかし「いない」でも「消えた」でもなかった。

---

「……データとして、生きている？」

　セラが低い声で言った。声が掠れていた。

　端末の表示が少し変わった。

```
記憶データとして保管。
本人の現在所在は未登録。
```

　「本人の現在所在は未登録」。体としてのソルがどこにいるか——それは分からなかった。記憶だけがある。体はない。あるいは登録されていないだけで、どこかにいるのか。分からなかった。

　セラが「会えるか？」と入力した。

　端末が数秒、停止した。

　返答はなかった。静止したまま、何も返さなかった。

　エコーのターミナルは普段、短い文字を返す。「確認中」「未登録」「処理完了」——どれかが来る。しかし今日の端末は何も返さなかった。「返答できない」という状態なのか、「処理中」なのか、それとも別の何かなのか。カインには分からなかった。セラも、分からなかった。

---

　カインがセラの手の横に立った。

「会えるかどうかより、どこにいるかを先に調べろ」

　セラが振り向いた。

「でも——」

「データがある。それは今日分かった。次に分かるのは、このデータを誰が入れたか、なぜここにあるか、だ。それが分かれば、次が見える」

　セラが端末の画面を見た。「保管中」という文字が静かにそこにあった。消えなかった。

「……ソルの記憶が、ここにある」

「ある」

「それは——ソルが、まだ、いるということですか」

　カインは答えなかった。

　「いる」と「データが存在する」は同じではない。しかし「いない」とも言えなかった。今日分かったのは「記憶データが保管されている」という事実だけだった。それ以上の意味を、今日のカインはセラに言える根拠を持っていなかった。

　セラが端末の前から一歩下がった。

　アンが後ろから少し手を伸ばしかけた。それから止めた。命令ではなかった——アン自身が「止めるべきか」と判断して、手を引いた。セラの肩に触れるまで、あと少しの距離だった。しかしアンは触れなかった。「命令でないことはするべきではない」という訓練が先に来た。その一秒の迷いが、アン自身には分からなかった。

　セラは振り返らなかった。アンは何も言わなかった。

---

　帰路だった。

　三人で歩いていた。境界の通路を抜け、下層に向かう路地に入った。

　カインが少し先を歩いていた。

　セラが「ありがとうございます」と言った。

「今日——一緒に来てもらって」

　カインは答えなかった。

「データがある、ということが分かりました。会えるかどうかは……まだ分からないけれど」

　セラがそこで止まった。

　カインも一歩手前で止まった。振り返った。

　セラが少しだけ笑った。泣いていない。しかし泣いていない顔が、笑っていない時より少し薄かった。何かを堪えているわけではないが、今日という日が何かを置いていった顔だった。

「ソルのことを……ジンさんはどんな顔で聞いてたんだろうって思いました」

　カインは答えなかった。

　「ジンさん」という言葉を聞いた瞬間、カインは少し止まった。一瞬だった。「なくなるまで気づかないんだよな、記憶って」——ジンの声ではなく、言葉だった。声は出てこなかった。言葉だけが来た。記憶の話をしていた時のジンの、短い言い方だった。それが今日、この場所で来た。

　カインは歩き出した。

---

　施設に戻ると、ミラが廊下の奥に立っていた。

　カインを見た。

「分かりましたか」

「データがあった。ソルという名前。登録年2395年。現在所在は未登録」

　ミラが少し頷いた。何も言わなかった。

「このデータを誰が入れたか、調べる方法はあるか」

　ミラがしばらく間を置いた。

「……一つ、あるかもしれません。ただし——確認には時間がかかります。それと」

「何だ」

「……私も、もう少し時間をください」

　カインはミラを一秒見た。ミラは目を逸らさなかった。何が言えないのかは分からなかった。言えない何かがある、ということは分かった。ミラは「いつかは話さないといけないと思っています」と以前言った。その「いつか」がいつなのかは、まだ来ていなかった。

　カインは廊下を歩いた。

---

　夜、エコーのターミナルの前に立った。

　今日の白化件数が出た。また誰かが消えた。ソルは「記憶データ / 保管中」だった。数字には入っていない。体がどこにいるかは分からない。記憶だけが存在する。

　エコーとは、記憶を管理するシステムだった。市民の記憶を保全し、管理し、保管する。Blancには適用されない——はずだった。しかしソルのデータはあった。2395年から。保管されていた。

　誰が入れたか。

　なぜ保管されているか。

　カインは端末の前から離れた。今日分かったことは一つだけだった。「ソルの記憶データがある」——それが事実だった。それ以外は、まだ何も分からなかった。分からないことが増えた。しかし「ある」ということを知る前と後では、何かが変わった。今日から「ソルはいない」とは言えなくなった。

---

```
【日記の断片】

データとは何か。
情報の集積か。記録の圧縮か。
私は違うと思っている。
データとは——そこにいたという証拠だ。
データが残る限り、その人間は「いた」。
```
