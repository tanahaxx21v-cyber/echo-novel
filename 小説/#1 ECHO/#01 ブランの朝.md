# ECHO 第1話「それでも朝は来る」

　昨日まで、この老人は自分の名前を言えた。

　カインは三叉路の前で足を止めた。

　老人がそこに立っていた。七十代か、それ以上か。バンドのない腕をだらりと下げて、どちらの通路も見ていない。立っているというより、そこに置かれているという感じだった。

　目が虚ろだった。何かを見ているようで、何も見ていない。三叉路のどちらへ行くかを決められないのではなかった。どちらが「道」であるかを、もう知らないのだ。

　一週間前に一度だけ言葉を交わしたことがある。「水を分けてくれないか」と言われて、持っていた一本を渡した。老人は「ありがとう、カインさん」と言った。声ははっきりしていた。そこに人間がいた。

　今朝の目は、別のものだった。

　白化だった。

　カインは老人の右腕を取った。抵抗はなかった。足が動いた。記憶が消えても、体が動くことを覚えている。全てが消えても、動けてしまう。それでも体は、生き続けていた。

　施設の入口まで連れて行き、中にいた女に任せた。

「また一人か」と女は言った。怒るわけでも嘆くわけでもなく、確認する声だった。

　カインは頷かずに出てきた。

　ダーク4番区の朝は、朝に見えない。天井から垂れ下がる誘導灯が一定間隔で点滅しているが、消えていないことを告げるだけの光だ。地下三百メートル——エコロン・セントラルの最下層。地上の太陽がここへ届いたことは一度もない。それでも時刻は六時二十分で、どこかの施設から子どもの声が聞こえる。

　カインは歩いた。

---

　施設に戻ったのは七時を過ぎた頃だった。

　ドアを開けると、小さなテーブルの上に包みが置いてあった。

　ジンがいた。

　入口の柱に背中を預けて、古い上着の袖口をいじっている。大柄な体が、この狭い廊下だと壁に見えた。腕の傷が外の光を反射して、古い工作の痕が線のように走っている。三十二歳の体が、三十二歳より少し多くのものを引き受けた形をしていた。

「遅かったな」

　それだけ言って、テーブルの包みをカインの方へ押した。

　乾燥させた保存食が二つ。水のボトルが一本。どこで手に入れたかは聞かなかった。ジンがこういうものを持ってくる時、出所を説明したことは一度もない。

　受け取った。

　何も言わなかった。

　ジンも、それでいいと知っていた。礼を言うという発想がカインの中にないのでも、感謝していないのでもない。言葉の代わりに何かが動いていて、それはジンには見えない。それでも機能していた。

　ジンはもう自分の部屋の方向へ歩いていた。

「飯食ったか？」

「今食う」

「そうか」

　それだけで終わった。

　廊下の奥に消えていく背中を見ながら、カインは包みを持ったまま椅子に座った。保存食を一口かじる。塩の味がする。熱量を摂取するだけの食事だ。

　老人の目が、まだ頭にあった。

　自分は白化しない。

　なぜかは知らない。二十六年間、記憶は消えたことがない。Blancである以上、白化から逃れる理由などないはずだ。その逆説に、カインはまだ答えを出せていない。

---

　八時になると、ミラが施設の廊下に出てきた。

　白衣は着ていない。いつもそうだ。薄い茶色のシャツに、くたびれた厚手のカーディガン。五十三歳の体が疲れを染み込ませているような立ち方をしているが、目だけが鋭かった。

「今日も、全員いるか」

　問いではなかった。確認だった。

　廊下にいた三人が顔を上げる。カイン、それからオルト、それからリン。

　オルトは椅子に腰かけたまま壁の一点を見ていた。六十七歳、白い髪が朝の誘導灯を反射している。話しかけると、答えが途中で止まることがある。どこかへ引っかかって、戻ってこれなくなる。

　リンは廊下の端に立って、袖の先端を両手で掴んでいた。十四歳。目だけは何かを見ていた。

「ジンは？」

「部屋にいる」とカインは答えた。

　ミラは小さく頷いた。肩から力を抜くような仕草をして、また廊下を歩き始めた。誰かの名前を呼んで、何人かに声をかけて、最後に施設の奥の小部屋へ消えた。

　毎朝、この確認がある。

　なぜかは、ミラは言わない。ただ「今日も全員いるか」と言って、確かめて、自分の仕事に戻る。

　オルトが口を開いた。

「……あの、カイン。今日は何日でしたか」

「七月の十四日だ」

「そうか。七月か」とオルトは言った。

　オルトはしばらく宙を見た。白い眉が寄る。何かを引っ張り出そうとしている顔だった。

「……七月に、何かあったような気がするのだが、何だったか」

　カインは答えなかった。

　外から補填しても、それはオルトの記憶ではない。記憶の輪郭だけが残って、中身は戻らない。

　オルトはまた壁に目を戻した。

「……まあ……」

　リンが廊下の端から、無言でどこかへ歩いていった。

---

　夜になった。

　カインは外へ出た。

　ダーク4番区の北端、区画の境界に近い壁の前に、古い端末がある。五年前に誰かが設置したまま誰も撤去しに来ない。画面は右端に一本、亀裂が入っているが、機能している。

　エコーのターミナルだった。

　[ECHO] という文字が、薄い緑のフォントで画面の左上に常時表示されている。白化の発生件数、記憶の移送ログ、システムの稼働状況。断片的な数字と記号が、画面を流れていく。

　カインは画面の前に立った。

　画面が更新された。

```
[ECHO：本日の白化発生件数：14件]
```

　14件。

　今日だけで、14人分の何かが消えた。今朝の老人の目が、また浮かんだ。14件という数字の中に、あの目が含まれているかどうか、カインには分からない。老人はBlancだった。バンドのない腕が、数字として数えられているのか。

　立ち去ろうとした。

　その瞬間、画面が変わった。

```
[ECHO：——]
```

　一秒あるかないかの間、何もなかった。

　「14件」も消えていた。「ECHO」の表記も消えていた。画面全体が、緑のフォントの残像だけを残して、空白になった。

　次の瞬間には戻っていた。

```
[ECHO：本日の白化発生件数：14件]
```

　カインは壁から背中を離して歩き始めた。

　ターミナルは、誰もいない通路で、静かに同じ数字を吐き続けていた。

```
真実は、公式記録の中に存在しない。
だからこそ、私は書く。
```
