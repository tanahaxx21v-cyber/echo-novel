# ECHO 第1話「それでも朝は来る」

　配管の継ぎ目から、水がしみ出していた。

　カインは壁を一度見て、通り過ぎた。誰も直さない。誰も直せない。ここでは、そういうことが多い。

　ダーク4番区の朝は、朝に見えない。

　天井から垂れ下がる誘導灯が一定間隔で点滅しているが、それは「光があること」を示しているにすぎない。消えていないことを告げるだけの光だった。地下三百メートル——エコロン・セントラルの最下層。地上の太陽がここへ届いたことは一度もない。

　それでも時刻は六時二十分で、どこかの施設から子どもの声が聞こえる。

　カインは歩いた。

　灰色のジャケットのポケットに手を入れたまま、古い通路を進む。コンクリートの床に、誰かが油性ペンで書いた文字があった。消されかけて、また書かれた跡がある。名前だったかもしれない。今はもう判別できない。泥の色をした壁が続き、頭上のパイプが振動するたびに砂粒が落ちてくる。機械油と湿気の混ざった臭いが通路に淀んでいた。一歩ごとに、靴底にコンクリートの硬さが伝わってきた。

　誰かとすれ違った。

　Blancの女だった。三十代か四十代か。腕にバンドはない——バンドのない腕が、この場所ではBlancの証だ。目線が低い。俯いて歩いている。カインは特に気に留めなかった。すれ違う人間の顔を覚えることを、この場所では誰もしない。明日も同じ顔がここにあるとは限らないから。

　通路が二手に分かれる場所を、右へ曲がった。

　角を曲がると、三叉路の前に人影があった。

　老人だった。

　七十代か、それ以上か。バンドのない腕をだらりと下げて立っている。背中が丸く、頭頂部の白い髪が誘導灯の光を反射していた。立っているというより、そこに置かれているという感じだった。三叉路の中心に立って、どちらの通路も見ていない。

　カインは足を止めた。

　昨日まで、この老人は自分の名前を言えた。

　一週間前に一度だけ言葉を交わしたことがある。「水を分けてくれないか」と言われて、持っていた一本を渡した。老人は「ありがとう、カインさん」と言った。名前を知っていた。声ははっきりしていた。眼差しは疲れていたが、そこに人間がいた。

　今朝の目は、別のものだった。

　虚ろだった。何かを見ているようで、何も見ていない。三叉路のどちらへ行くかを決められないのではなかった。どちらが「道」であるかを、もう知らないのだ。「誰かがいた」という感覚だけが残って、その誰かが誰だったかは、もう分からなくなっていた。その消え方を、カインは何度も見ていた。この場所で育った二十六年間で。

　白化だった。

　名前を呼ぶことを考えた。しかし名前を聞いたことがなかった。「カインさん」とこちらを呼んでいた老人の名前を、カインは知らなかった。

　カインは老人の前に立ち、顔を見た。目が合った、と感じたが、合ってはいなかった。老人の目は焦点を持っていなかった。カインのいる場所を通り抜けて、どこか別の場所を見ていた。見ることをやめていた。

　右腕を取った。

　抵抗はなかった。足が動いた。誘導するように歩いた。老人はついてきた。記憶が消えても、足が動くことを体が覚えている。全てが消えても、動けてしまう。それでも体は、生き続けていた。

　施設の入口まで連れて行き、中にいた女の人間に任せた。

「また一人か」と女は言った。怒るわけでも嘆くわけでもなく、確認する声だった。

　カインは頷かずに出てきた。

　外に出ると、また配管の水音がしていた。ダーク4番区は今日も変わらなかった。変わることを許されていないように、毎朝同じ形をしている。

---

　施設に戻ったのは七時を過ぎた頃だった。

　ドアを開けると、小さなテーブルの上に包みが置いてあった。

　ジンがいた。

　入口の柱に背中を預けて、古い上着の袖口をいじっている。大柄な体が、この狭い廊下だと壁に見えた。腕の傷が外の光を反射して、古い工作の痕が線のように走っている。三十二歳の体が、三十二歳より少し多くのものを引き受けた形をしていた。

「遅かったな」

　それだけ言って、テーブルの包みをカインの方へ押した。

　乾燥させた保存食が二つ。水のボトルが一本。どこで手に入れたかは聞かなかった。ジンがこういうものを持ってくる時、出所を説明したことは一度もない。聞いても「知り合いのとこで拾ってきた」としか言わないことを、カインは知っていた。それ以上は聞かなかった。聞く必要がなかった。

　受け取った。

　何も言わなかった。

　ジンも、それでいいと知っていた。礼を言うという発想がカインの中にないのでも、感謝していないのでもない。言葉の代わりに何かが動いていて、それはジンには見えない。

　互いにそれを確認したことはない。

　それでも機能していた。

　ジンはもう自分の部屋の方向へ歩いていた。

「飯食ったか？」

「今食う」

「そうか」

　それだけで終わった。

　廊下の奥に消えていく背中を見ながら、カインは包みを持ったまま椅子に座った。保存食を一口かじる。塩の味がする。熱量を摂取するだけの食事だ。しかし今は十分だった。

　老人の目が、まだ頭にあった。

　虚ろさの形をしていた目。「誰かがいた」という残像だけを運んでいた目。白化が来る前と後で、人間の目はどう変わるのか。どこかのタイミングで急に変わるのか、それとも少しずつ薄れていくのか。カインには分からない。

　自分は白化しない。

　なぜかは知らない。二十六年間、記憶は消えたことがない。Blancである以上、白化から逃れる理由などないはずだ。その逆説に、カインはまだ答えを出せていない。

　保存食を食い終えて、壁に目を向けた。

　窓はない。ここには一つも窓がない。外がどうなっているかを見る手段が、この場所にはない。上層がどんな光の中にあるのかを、カインは見たことがない。中層の灰色の廊下は見たことがある。しかし本当の意味での「外」は、ここからでは届かない。

---

　八時になると、ミラが施設の廊下に出てきた。

　白衣は着ていない。いつもそうだ。薄い茶色のシャツに、くたびれた厚手のカーディガン。五十三歳の体が疲れを染み込ませているような立ち方をしているが、目だけが鋭かった。手が微かに震えているのに気づいたのは一年ほど前からだ。聞いたことはない。

「今日も、全員いるか」

　問いではなかった。確認だった。

　廊下にいた三人が顔を上げる。カイン、それからオルト、それからリン。

　オルトは椅子に腰かけたまま壁の一点を見ていた。六十七歳、白い髪が朝の誘導灯を反射している。目が遠くを見ている。今日が何日かを知っていても、何年かを正確に言えない日がある。記憶が欠けているのだ。欠け方が日によって違う。話しかけると、答えが途中で止まることがある。どこかへ引っかかって、戻ってこれなくなる。

　リンは廊下の端に立って、袖の先端を両手で掴んでいた。十四歳。目だけは何かを見ていた。

「ジンは？」

「部屋にいる」とカインは答えた。

　ミラは小さく頷いた。肩から力を抜くような仕草をして、また廊下を歩き始めた。誰かの名前を呼んで、何人かに声をかけて、最後に施設の奥の小部屋へ消えた。

　毎朝、この確認がある。

　何年前からあるのかをカインは正確に覚えていないが、記憶にある限りずっとあった。理由を言ったことはない。ただ「今日も全員いるか」と言って、全員いることを確かめて、また自分の仕事に戻る。それだけだ。

　その「それだけ」が何かを意味していることをカインは知っている。しかし何の意味かは、まだ名前をつけられていない。

　オルトが口を開いた。

「……あの、カイン。今日は何日でしたか」

「七月の十四日だ」

「そうか。七月か」とオルトは言った。

　オルトはしばらく宙を見た。白い眉が寄る。何かを引っ張り出そうとしている顔だった。

「……七月に、何かあったような気がするのだが、何だったか」

　カインは答えなかった。

　答えを知っているかどうかではなく、その問いに答えを出すことがオルトの助けになるかどうかを一瞬考えた。オルトが「七月に何かあった」と感じているなら、その「何か」はオルトの中にある。外から補填しても、それはオルトの記憶ではない。記憶の輪郭だけが残って、中身は戻らない。

　オルトはまた壁に目を戻した。

「……まあ……」

　全部が消えるのではなく、「あった気がする」という感覚だけが残る。形だけが残って中身が空になる。それが白化だとカインには見えた。

　リンが廊下の端から、無言でどこかへ歩いていった。

　静かな朝だった。

---

　午後になると、施設の中に人が増えた。

　ダーク4番区に住むBlancたちは、どこかに仕事があるわけではない。上層にも中層にも仕事はある。しかしBlancは公式記録上存在しないため、雇用される手段がない。だから昼間は施設に来て、いる。あるいはどこかの通路を歩いて、時間を過ごす。

　カインは施設の外の壁に背中を預けて、古い資料を読んでいた。

　エコーの稼働ログの断片だ。上層から流れてきたか誰かが持ち込んだか、出所の分からない古いプリントで、端が破れている。数字と記号が並んでいる。記憶移送のログだった。何年前のものかは読み取れない。

　「記録がある」ということが、カインには不思議に思えた。

　エコーはこれだけの情報を管理している。誰が何の記憶を持っていて、誰が何を失ったか。全てが数字として記録されている。数字は消えない。記録は残る。記憶は消えても、記録は残る。

　カインはプリントの数字の列を一度見た。数字は静かにそこにあった。

　人間の記憶が消えても、その記録は残る。記録の中には消えた人間がいる。それは「いた証拠」なのか、「消えた証拠」なのか。

　答えは出なかった。

　ジンが外に出てきて、カインの隣に腰を下ろした。

「何読んでるんだ」

「エコーのログ」

「また難しいもん読んでるな」

　笑って、腕を組んだ。カインは読み続けた。

　しばらく二人で黙っていた。

　ジンが誘導灯を見上げて、何かを言いかけて、やめた。それからもう一度見上げて、今度は言った。

「昔は、本物の光があったらしいぞ。地上の」

「知ってる」

「見たいとは思わないか」

「思ったことない」

　ジンは少し黙った。

「俺は思うけどな。見たい」

　カインは資料から目を上げた。ジンが空を見るような目で天井を見ていた。天井には光源しかない。それでも、その目には何か別のものが映っていた。

　カインは黙った。

---

　夜になった。

　施設の人間が眠ると、廊下は静かになる。誘導灯の点滅だけが時間を数えている。

　カインは外へ出た。

　ただ、体が動いた。いくつかの夜に、足がここへ向かう。今夜もそういう夜だった。

　ダーク4番区の北端、区画の境界に近い壁の前に、端末がある。古い型のターミナルだ。五年前に誰かが設置したまま誰も撤去しに来ない。画面は右端に一本、亀裂が入っているが、機能している。

　エコーのターミナルだった。画面の熱が、夜の冷えた空気の中でわずかに伝わってきた。

　[ECHO] という文字が、薄い緑のフォントで画面の左上に常時表示されている。そのフォントが、通路の壁に細い影を落としていた。エコロン・セントラルの記憶管理AIが、このターミナルを通じて情報の一部を吐き出している。白化の発生件数、記憶の移送ログ、システムの稼働状況。断片的な数字と記号が、画面を流れていく。

　カインは画面の前に立った。

　ここには全てが記録されている。

　それは確かだ。この都市で起きた全ての「出来事」が、どこかのサーバーの中に存在する。誰が生まれて誰が白化して誰が失われたか、全てがデータとして積み重なっている。

　しかし。

　カインは画面を見ながら考えた。

　なぜ、記録が存在するのか。エコーが管理している——それは分かる。しかし記録とは何のためにあるのか。誰かに届けるためか。証明するためか。

　分からない。しかし知りたかった。

　画面が更新された。

```
[ECHO：本日の白化発生件数：14件]
```

　14件。

　今日だけで、14人分の何かが消えた。名前が消えた者もいるだろう。顔が消えた者もいるだろう。どこかの三叉路で立ち止まった者もいるだろう。

　今朝の老人の目が、また浮かんだ。

　14件という数字は、エコロン・セントラル全体のものだ。ダーク4番区だけではない。上層でも、中層でも、今日誰かが何かを失った。しかしその14件の中に、今朝の老人が含まれているかどうか、カインには分からない。老人はBlancだった。あの目が、この数字の中にあるのか。バンドのない腕が、数字として数えられているのか。

　分からなかった。

　どちらが正しいのかも、この画面では分からなかった。

　エコーが何を記録して、何を記録しないのかを、誰かが——あるいは何かが——決めている。この都市の記憶の全てを握っているそれが、どういう基準で記録を選んでいるのかを、カインは知らない。

　カインは画面から目を離して、壁に背中を預けた。夜のダーク4番区は昼より静かだが、静かさの質が違う。昼の静かさは音がないだけだ。夜の静かさは、何かが息を潜めている感じがする。水の染みる音だけが、通路のどこかから聞こえる。

　立ち去ろうとした。

　その瞬間、画面が変わった。

```
[ECHO：——]
```

　一秒あるかないかの間、そこには何もなかった。

　文字が、文字を形成するのをやめていた。「14件」も消えていた。「ECHO」の表記も消えていた。画面全体が、緑のフォントの残像だけを残して、空白になった。

　次の瞬間には戻っていた。

```
[ECHO：本日の白化発生件数：14件]
```

　カインはすでに壁から背中を離して歩き始めていた。靴音が通路の奥へ消えていく。

　ターミナルは、誰もいない通路で、静かに同じ数字を吐き続けていた。

---

```
【日記の断片】

私はこの記録を、誰に読まれるためでもなく書き始めた。
真実は、公式記録の中に存在しない。
だからこそ、私は書く。
```
