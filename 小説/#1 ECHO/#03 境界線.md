# ECHO 第3話「境界線」

　セラが施設に来て、三日が経っていた。今日、中層に行く。

　カインは朝から外に出る準備をしていた。ポケットに何が入っているかを確かめる。水。乾燥食。それだけあれば十分だった。ジャケットを着る。古いが、中層に行くなら上着がいる。袖を引き下げた。配管の継ぎ目から水がにじんでいた。誘導灯が点滅を繰り返している。ダーク4番区の朝だった。

　廊下に出ると、ジンが壁に寄りかかっていた。

「どこ行くんだ」

「中層」

　ジンは腕を組んだ。しばらく黙った。

「セラのためか」

「ソルという子どもの記録を調べる。中層を当たってみる」

　ジンは少し目を細めた。何かを考えている顔だった。

「地図は持ってるか」

「中層なら分かる」

「そうか。なら良い」

　短い間があった。ジンは続けた。

「俺、あのバンドが気になってたんだ。上から生きて降りてくる奴は、今まで見たことがなかった。上から来るのは大抵、記録の紙だ。人間じゃない。あの女が来た時、これは何かが動いてると思った。だから行かせた」

　カインは何も言わなかった。ジンは続けた。「お前が出かけた方がいいと思った。ずっとここにいるのもよくない」

「気をつけろよ」

　背中に声がかかった。カインは振り返らなかった。

「分かった」

　ジンが何かを言い足す気配があった。しかし何も来なかった。

　外に出て少し歩いてから、立ち止まった。「分かった」と答えたことを、少し後から考えた。ジンに「気をつけろよ」と言われることは珍しくない。しかしカインが「分かった」と返したことは、そうではなかった。

　ジンはいつも、気をつけろとは言う。カインは今まで何も答えなかった。今日はなぜ答えたのか。分からないまま、北東の方向へ歩いた。

---

　ダーク4番区から中層への境界は、北東の端にある。

　鉄製の扉に、読み取り端末が取り付けられていた。IDバンドを当てる方式だ。Blancにはバンドがない。この扉の前を通ったことは何度かあったが、試したことはなかった。試す理由がなかった。

　今日まで。

　端末の前に立った。

　光が走った。スキャン範囲に入った瞬間、機械の稼働音が少し変わった。

```
[対象データなし]
[読み取りエラー / 障害コード：ERR-404]
[処理：通過許可（後日点検）]
```

　三秒。

　扉が開いた。

　カインは通った。

　少し歩いてから立ち止まり、後ろを見た。扉は閉まっていた。

　仕組みは分かった。記録がない者に対して、機械は自分が故障したと判定する。Blancは、機械を見失わせる。

　カインは歩き始めた。

---

　中層の通路は、下層より広かった。天井が高く、壁が乾いている。においがない。下層に染みついた配管と湿気のにおいがここには届かない。コンクリートではなく別の素材の床が音を吸っている。足音が沈む。誘導灯ではなく、固定された白い光源が一定間隔にある。光が点滅しない。安定した光の下を、Ordis市民が行き交っていた。

　灰色のバンドを着けた女が子どもの手を引いている。灰色のバンドの男が手元の端末を見ながら歩く。誰もカインを見ない。中層ではBlancかどうかを外見で判断できない。バンドのない腕が問題になるのは、記録の照合が行われた時だけだ。カインはその事実を初めて体で理解した。

　通路を二つ折れたところに、公共記録端末があった。壁に埋め込まれている。

　カインは端末の前に立った。バンドなしのゲスト照会を選んだ。公開記録のみ。それで十分だった。

　「ソル」と入力した。

　複数件がヒットした。条件を絞る。六年前。年齢。上層区画。

　一件になった。

```
[ソル / 2389年生 / MemOris区・第三番区 / 記録ステータス：抹消済 / 処理日時：2395年]
```

　「抹消済」という表示を、しばらく見た。白化した記録は「消失」と表示される。「抹消済」は、誰かが意図的に消した、という意味だ。消すのは事故ではない。誰かが判断した。それだけ分かれば十分だった。

　抹消した主体を調べようとした。公開記録の端末では、処理コードの詳細は出てこなかった。表示されたのは一行だけだった。

```
[処理区分：上位権限（ハイブ管轄）]
```

　上層が消した。

　なぜ上層が一人の子どもの記録を消す必要があったのか。六歳の子どもを。この端末では調べられない。カインは端末の前から離れた。

　答えは中層にはない。上層にある。

---

　施設に戻ったのは昼を過ぎた頃だった。中層からの帰路は、往路と同じく境界を問題なく通れた。下層に足を踏み入れると、においが戻った。配管と湿気の混ざった臭い。それが、ここだった。誘導灯が点滅している。下層の光。

　入口の近くでジンが端材を削っていた。乾いた音が廊下に広がっていた。カインが戻るのを見て、上から下まで確かめる目を一度向けた。

「戻ったか」

「ああ」

　ジンはそれだけ言って、また端材に視線を落とした。怪我がないかを一秒で確かめた後の顔だった。

　廊下を進むと、セラが小部屋の前に立っていた。ずっとそこで待っていたような立ち方だった。カインに気づいて、少し体を起こした。

「ソルの手がかりはなかった」

　セラの表情が小さく動いた。覚悟していたような顔だった。

「でも道は見つけた」

　セラが目を上げた。初めてそこに何かが宿った目だった。

「ソルの記録は六年前に上層が消した。なぜ消したかは、中層では調べられない。上層なら調べられる。そして、上層には行ける」

「……上層が、消した」

　セラは繰り返した。声が少し低くなっていた。何かを確かめるように言った言葉だった。しばらく、黙った。六年分の何かが動いているような静けさだった。それから顔を上げた。

「行けるんですか、上層に」

「今日、中層まで行けた。同じ方法で上層まで行ける」

「一緒に連れて行ってもらえますか」

「今は一人で行く」

　セラは何も言わなかった。少しの間、カインの顔を見た。何かを言おうとして、やめた。表情だけが動いた。それからうつむいた。

「……分かりました」

　カインは廊下の奥へ歩き始めた。数歩あるいたところで、セラが言った。

「……気をつけてください」

　返事はしなかった。廊下の奥へ歩いた。セラがまだそこに立っているのが、気配でわかった。

　入口の方向から、少し間をおいてジンの声がした。

「いつも返事が少ない奴だから、気にするな」

　その夜、カインはECHOのターミナルを一度だけ確認した。白化件数が更新されていた。今日も誰かが消えた。それは毎日起きていた。記録を消される人間と、記録が消える人間がいる。消される方には、理由がある。誰かが必要としたということだ。六歳の子どもを消す必要があった。それがどういう事情からくるのか——その問いを、カインはまだ持ち帰れていなかった。
