# ECHO 第3話「境界線」

　セラが施設に来て、三日が経っていた。今日、中層に行く。

　カインは朝から外に出る準備をしていた。ポケットに何が入っているかを確かめる。ジャケットを着る。配管の継ぎ目から水がにじんでいた。誘導灯が点滅を繰り返している。ダーク4番区の朝だった。

　廊下に出ると、ジンが壁に寄りかかっていた。

「どこ行くんだ」

「中層」

　ジンは腕を組んだ。しばらく黙った。

「セラのためか」

「ソルという子どもの記録を調べる。中層を当たってみる」

　ジンは少し目を細めた。何かを考えている顔だった。

「俺、あのバンドが気になってたんだ。上から生きて降りてくる奴は、今まで見たことがなかった。上から来るのは大抵、記録の紙だ。人間じゃない。あの女が来た時、これは何かが動いてると思った。だから行かせた」

　カインは何も言わなかった。

「気をつけろよ」

　背中に声がかかった。カインは振り返らなかった。

「分かった」

　外に出て少し歩いてから、立ち止まった。「分かった」と答えたことを、少し後から考えた。ジンに「気をつけろよ」と言われることは珍しくない。しかしカインが「分かった」と返したことは、そうではなかった。

---

　ダーク4番区から中層への境界は、北東の端にある。

　鉄製の扉に、読み取り端末が取り付けられていた。IDバンドを当てる方式だ。Blancにはバンドがない。この扉の前を通ったことは何度かあったが、試したことはなかった。試す理由がなかった。

　今日まで。

　端末の前に立った。

　光が走った。スキャン範囲に入った瞬間、機械の稼働音が少し変わった。

```
[対象データなし]
[読み取りエラー / 障害コード：ERR-404]
[処理：通過許可（後日点検）]
```

　三秒。

　扉が開いた。

　カインは通った。

　少し歩いてから立ち止まり、後ろを見た。扉は閉まっていた。

　仕組みは分かった。スキャンシステムは記録のある者を通す設計だ。記録がなければ、自分が壊れたと判定する。

　Blancは記録がない。だから機械が、自分を見失った。

　カインは歩き始めた。

---

　中層の通路は、下層より広かった。天井が高く、壁が乾いている。においがない。下層に染みついた配管と湿気のにおいがここには届かない。誘導灯ではなく、固定された白い光源が一定間隔にある。光が点滅しない。安定した光の下を、Ordis市民が行き交っていた。

　灰色のバンドを着けた女が子どもの手を引いている。灰色のバンドの男が手元の端末を見ながら歩く。誰もカインを見ない。中層ではBlancかどうかを外見で判断できない。バンドのない腕が問題になるのは、記録の照合が行われた時だけだ。

　公共記録端末が通路の壁に埋め込まれていた。

　カインは端末の前に立った。バンドなしのゲスト照会を選んだ。公開記録のみ。それで十分だった。

　「ソル」と入力した。

　複数件がヒットした。条件を絞る。六年前。年齢。上層区画。

　一件になった。

```
[ソル / 2389年生 / MemOris区・第三番区 / 記録ステータス：抹消済 / 処理日時：2395年]
```

　「抹消済」という表示を、しばらく見た。白化した記録は「消失」と表示される。「抹消済」は、誰かが意図的に消した、という意味だ。それだけ分かれば十分だった。

　抹消した主体を調べようとした。公開記録の端末では、処理コードの詳細は出てこなかった。表示されたのは一行だけだった。

```
[処理区分：上位権限（ハイブ管轄）]
```

　上層が消した。

　なぜ上層が一人の子どもの記録を消す必要があったのか。この端末では調べられない。カインは端末の前から離れた。

---

　施設に戻ったのは昼を過ぎた頃だった。

　入口の近くでジンが端材を削っていた。カインが戻るのを見て、一度目を上げた。

「戻ったか」

　それだけで、作業に戻った。

　廊下を進むと、セラが小部屋の前に立っていた。カインに気づいて、少し体を起こした。

「ソルの手がかりはなかった」

　セラの表情が小さく動いた。覚悟していたような顔だった。

「でも道は見つけた」

　セラが目を上げた。

「ソルの記録は六年前に上層が消した。なぜ消したかは、中層では調べられない。上層なら調べられる。そして、上層には行ける」

「……上層が、消した」

　セラは繰り返した。声が少し低くなっていた。何かを確かめるように言った言葉だった。しばらく、黙った。それから顔を上げた。

「行けるんですか、上層に」

「今日、中層まで行けた。同じ方法で上層まで行ける」

「一緒に連れて行ってもらえますか」

「今は一人で行く」

「……分かりました」

　カインは廊下の奥へ歩き始めた。

---
