# ECHO 第4話「値段のついた記憶」

　ソルの記録は上層が消した。しかし消えたのは記録だけかもしれなかった。

　翌朝、カインはセラに言った。

「記憶マーケットに行く。来い」

　セラが少し目を見開いた。「来い」と言われることを予期していなかった顔だった。

「……一緒に行っていいんですか」

「ソルのことで、確かめることがある」

　セラは頷かなかった。ただ「分かりました」と言って上着を取りに戻った。

---

　中層への道は、昨日通った北東の境界だ。

　カインが先に歩いた。セラは少し遅れてついてくる。言葉を交わさないまま、二人は境界の端末を通過した。昨日と同じように扉が開いた。セラは入口で少し止まったが、カインは振り返らなかった。

　中層の通路は昨日と変わらない。音を吸う床。点滅しない光。においのない空気。灰色のバンドをつけた人間が行き交っている。誰も立ち止まらない。誰も声を上げない。全員が、それぞれの目的地へ向かっている。

　しばらく歩いてから、セラが言った。

「……ここが中層」

「初めてか」

「はい」

　カインは歩き続けた。

「見回さない方がいい。バンドのない腕が見える」

　セラは右腕を少し左手で隠した。カインはそれを見ていた。六歳の子どもを探しに下層まで来た人間が、今初めて中層に入っている。どういう経路で下まで降りてきたのか、まだ聞いていなかった。

　記憶マーケットは北回廊の三番扉の奥にある。

---

　三番扉を開けると、音が薄くなった。

　外の通路の人の気配が、ここには届かない。においもなかった。清潔というより、何かが抜けた空気だった。取引される記憶の痕跡が消えた場所——そういう空気だった。

　店主は壁の端に立っていた。中年の男で、カインを一度見て、セラを一度見た。バンドを確認した。灰色のバンドが二本。問題ないと判断した顔で、視線を戻した。

　入口の板に値段表が出ていた。

```
[一般記憶（事実・知識）：12〜40ゴール]
[感情記憶：250〜800ゴール]
[子どもの記憶（感情）：1,200ゴール〜]
```

　セラが立ち止まった。

「子どもの記憶が……一番高いんですか」

「感情が純粋なほど値が上がる。子どもの記憶は混じりけがない」

　カインは値段表を読み上げたわけではなかった。セラの問いに答えただけだった。しかし言葉にした瞬間、何かを確かめるような気がした。一番高いのは「純粋さ」だ。純粋である子どもの記憶から何かを取り出すとき、何が残るのか。

　セラは何も言わなかった。それだけ聞ければ十分だった、という顔だった。

　カインは奥へ進んだ。

---

　照会端末は奥の壁に並んでいた。

　出品中の記憶一覧が表示されている。年代・年齢・感情種別で絞り込める。カインは条件を入れた。MemOris区。六歳。六年前。感情記憶。

　一件ヒットした。

```
[ソル / 2389年生 / MemOris区 / 6歳時感情記憶 / 出品者：非公開 / 内容：非公開 / 価格：要問い合わせ]
```

　セラが息を止めた。

　端末を見ている目が動かなくなった。手が端末に伸びかけて、止まった。画面に触れても何も変わらないことを、触れる前に分かっているような止まり方だった。

　連れてくるべきではなかった。そう考えた。答えは出なかった。

「出品者は非公開だ。内容も見られない。誰が売ったかは分からない」

「ソルの記憶も……」

　声が止まった。セラは口を閉じた。

「あるいは、売られようとしている」

　セラはしばらく端末を見た。[ソル / 6歳 / 感情記憶]という文字だけがある。その先は何もない。それでも十分な重さがあった。

「ここにあるかもしれない」——その言葉を、セラは言わなかった。

　カインはそれを見ていた。セラの横顔を一度だけ見た。表情が動いていない。何かを堪えているというより、何かを処理しきれずに止まっている、という顔だった。セラがなぜ言わないのかは分かった。言ってしまえば「あるかもしれない」という可能性を自分で確定してしまうからだ。言わないことで、まだ「ないかもしれない」を保っている。

　カインは端末から手を離した。

「六年前に上層が記録を消した。同じタイミングでここに出品された。繋がっている可能性がある」

「上層が……売ったんですか」

「分からない。売るよう命令した可能性もある」

　セラはもう一度、端末の文字を見た。それから顔を上げた。

「調べ続けましょう」

　カインは何も言わなかった。

---

　施設に戻ったのは夕方だった。

　廊下でミラが出てきた。「どうだった」

「記憶が売れる。子どもの感情記憶が高かった」

　ミラは少し間を置いた。何かを考えている顔だった。それから「そうか」と言って、手元のファイルをひとまとめにした。素早く閉じた。表紙に「K」の文字が見えた。

　閉じた理由は言わなかった。カインは何も聞かなかった。

「セラは何か言ったか」

「ソルの記録が出品されていた。内容と出品者は非公開だった」

　ミラは頷いた。何かを確認するような沈黙が一秒あった。それから「上層に行くのか」と言った。

「ゆくゆくは」

「気をつけろ」

　それだけで廊下の奥へ歩いていった。「K」のファイルのことは言わなかった。

---

　通路の角で、リンが壁際に立っていた。手に小さな包みを持っている。

　リンはカインを見て、少し間を置いた。それから包みを差し出した。

「……食べる？」

　奥からジンが出てきた。「少ないけどな」と言いながら、リンの手元に何かを足した。

「……うん」とリンが受け取った。カインを知っている顔でジンを見た。

　カインは包みを受け取った。何も言わなかった。施設に帰ってきた、という感覚だった。外から戻ると毎回それがある。今日は中層に二度入った。どちらの往復でも、施設に戻ったときに感じた。ここに帰ってきた、という感覚を。

　なぜまだここにいるのか。その問いが、もう何度目かになる。

---

　夜、廊下を歩いていると、セラが部屋の前に立っていた。

　壁に手をついて、うつむいている。配管の音が低く続いていた。

　カインは立ち止まった。

　なぜまだここにいるのか、という問いが浮かんだ。帰す理由も置いておく理由も、どちらも言葉にならない。この数日で同じ問いが何度か浮かんで、そのたびに答えが出なかった。今日もそうだった。

　声をかけようとして、やめた。

　廊下の奥へ歩いた。

　端末の表示が頭の端に残っていた。出品者は非公開だった。ソルの感情記憶を、誰かが売った。誰が、なぜ。その問いに答えは出なかった。上層に行く必要がある、とだけ思った。ソルはまだどこかにいるのか。記憶が売られていても、本人がどこかにいる可能性は消えていない。

---

```
【日記の断片】

感情記憶が最も高値だった。
喜びと痛みは同じ価格がついた。
私はそれを聞いて、この世界が何を間違えたかを理解した。
感情とは売れるものではない。感情とは、経験の積み重ねだ。
それを取り出した瞬間、その人間は少し死ぬ。
```
