# ECHO 第16話「データの中の名前」

　記憶アーカイブ塔は、中層の最奥にあった。

　評議局が管理する大きな建物で、外壁に窓がなかった。外部端末が塔の前に並んでいた——記憶データの一般照会に使う端末だ。内部へのアクセスはできない。「MemOris区の記憶保管状況を市民が確認できる」という建前の設備だった。

　セラのバンドをかざした。

---

「照会対象を入力してください」

「ソル。2389年生。MemOris区」

　少しの間があった。

```
[ソル / 記憶データ / 保管中 / 2395年〜]
[担当区分：評議局管轄]
```

　セラが動かなくなった。

---

「……データとして、生きているんですか」

　端末の画面が更新された。

```
[ECHO：記憶が保管されているだけです]
[ECHO：生体機能との関連は管轄外の情報です]
```

「会えるか？」

　セラが端末に向かって言った。

　画面が止まった。

　五秒。

　画面が止まったまま、何も表示されなかった。エコーは答えなかった。

---

　アンが一歩前に出かけた。セラの肩の方向に手を伸ばしかけた——そして止めた。手を下ろした。命令が出たわけではなかった。次の動作に移った。

---

　カインは端末の表示を見ていた。

「ソル / 記憶データ / 保管中」

　少し、止まった。

　「なくなるまで気づかないんだよな、記憶って」——その声が、一瞬だけあった。すぐに、なかった。

---

「会えるかどうかより、どこにいるかを先に調べろ」

「……はい」

「「保管中」なら場所がある。場所が分かれば次が分かる」

　セラが端末から離れた。一度だけ振り返った。また前を向いた。

---

　帰路は少し長かった。

　セラが何も言わなかった。アンも何も言わなかった。カインも言わなかった。

　「データが残る限り、いた」ということだ——カインは、そう理解した。それが何を意味するかは、まだ分からなかった。

---

```
【日記の断片】

データとは何か。
情報の集積か。記録の圧縮か。
私は違うと思っている。
データとは——そこにいたという証拠だ。
データが残る限り、その人間は「いた」。
```
