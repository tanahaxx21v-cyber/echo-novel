# ECHO 第15話「処理済み」

　評議局の支局に侵入したのは、翌々日だった。

　フェールオープン。中に入った。廊下を進んだ。記録室への扉は施錠されていたが、読み取り端末の前に立てば開いた。記録がない者が来た——エラー——通過許可。同じ手順だった。

　何をするために来たのかは、まだ整理できていなかった。ジンの記録を見る——それだけが目的として言語化できた。他に何かをするかどうかは、着いてから考えることにした。

　ジンの記録を探した。

　Blancに記録はない。ジンの名前を入れても何も出ない——それは分かっていた。「転落事故」という処理記録を探した。日付を入れた。区画を入れた。

```
[区画内事故記録 / 7月26日 / 男性 / Blanc / 転落 / 処理済み]
```

　三行だった。ジンの名前はなかった。生きていた証拠もなかった。死んだ証拠もなかった——ただ「処理済み」と書かれていた。

　この記録がなければ、ジンが存在したという証拠は何もない。施設の仲間がジンを知っている——それだけだ。知っている人間が全員いなくなれば、ジンが生きた時間は、どこにも残らない。

　端末を破壊しようとした。

　止まった。

　記録を消しても、ジンは戻らない。消えても変わらない。消さなくても変わらない——それが分かっていて、それでも来た。来る必要がなかった。来た理由が何だったのかは、今日も分からなかった。

　端末から離れた。廊下を歩いた。

　ジンは「なくなるまで気づかないんだよな、記憶って」と言った。白化の話をしていたが、今は別のことに聞こえた。カインがジンの「気をつけろよ」に「分かった」と一度だけ答えた朝——ジンはその後一秒だけ手を止めた。今になって思う。あの一秒が何だったのかを。

---

　帰り道の廊下で、評議局の別の部屋の扉が開いていた。

　カインは通り過ぎようとして止まった。

　部屋の中に男がいた。制服を着ていた。机に向かっていた。手元に報告書があった。

　男が報告書を読んでいた。

　表紙に「白化促進プログラム完了 / 第三フェーズ」という文字が見えた。

　男は報告書を読み終えた。それから、報告書を机に置いた。

　窓の外を見た。

　長い沈黙だった。

　何を考えていたかは、カインには分からなかった。何も読み取れなかった。ただ、その沈黙は長かった。報告書に書かれていた内容を受け取った後の、何かを消化しようとする沈黙に見えた——それだけは感じた。

　男が扉に気づいた。カインを見た。

　レイドだった。

　レイドはカインを見た。何も言わなかった。一秒の後、扉が閉まった。カインは廊下を歩いた。

　「白化促進プログラム完了」という文字と、あの沈黙が、頭の端に残った。「完了」を受け取った後に「長い沈黙」がある——それが何を意味するのかを、カインは考えながら廊下を進んだ。答えは出なかった。レイドの沈黙は、何も語らなかった。語らないことが、何かを語っているのかもしれなかった。

---

　施設に戻ると、ミラが廊下で書き物をしていた。

　施設の日誌だった。

　カインが通ると、ミラは書き続けていた。カインはその手元が少し見えた。

```
私は記録を残さないといけない。
```

　文体が違う。ミラの普段の文字の書き方と違った——正確には、同じ丁寧な字だったが、口調が違った。「私」という一人称。格調のある書き方。「分かってほしいため」に書いているような文体。施設の日誌というより、別の何かのような書き方だった。

　カインが少し立ち止まった。

「何を書いてるんですか」

　ミラが顔を上げた。

「施設の記録です」

「「私は記録を残さないといけない」という書き方をしているのか」

　ミラが少し間を置いた。

「……書き方の癖です」

　それだけ言って、ミラは日誌を閉じた。

　カインは廊下を進んだ。「記録を残さないといけない」——その言葉が、何かに引っかかった。引っかかった理由が何かは、まだ分からなかった。

---

　セラが小部屋の前に立っていた。

「ジンさんの席が……」

　セラが言いかけた。止まった。

「カイン、今日も……評議局に行きましたか」

「ああ」

「一人で」

「ああ」

　セラは少し間を置いた。

「……私は、本当にジンさんのことを悲しんでいるのだろうか」

　声が低かった。カインに向けて言ったのか、自分に言ったのか、どちらとも取れた。

「ジンが死んだことが……悲しいとは思っているんです。でも、その悲しさが本物かどうかが——分からなくて」

「本物じゃない悲しさがある、ということか」

「……そういうわけじゃないんですが。でも、ソルのことを思う時の感覚と、ジンさんのことを思う時の感覚が——違うんです。どちらが本物か、という意味じゃなくて——」

　セラは途中で止まった。

「うまく言えません」

「分からなくていい」

「でも——」

「全部の悲しみに名前がつく必要はない」

　セラは黙った。しばらく間があった。

「……そうですね」

　それだけだった。

　セラは続けた。

「自分の感情が本物かどうか確かめる方法が……ないんです。確かめようとすると、確かめているという行為に邪魔されて——それが私のものなのか、ただの反応なのか、分からなくなる」

　カインは答えなかった。

「……カインは、そういうことはありますか。自分の感情が本物かどうか疑うこと」

「ある」

「どうするんですか」

「分からないまま、動く」

　セラが少し考えた。

「……それでいいんですね」

「それしかない」

　カインは廊下を進んだ。

---

　夜、エコーのターミナルの前に立った。

　白化件数が更新されていた。今日も数字が動いた。ジンはBlanc——記録がなければ、数字にも入らない。ジンが死んだという事実は、どこにも残らない。評議局の「転落事故」の三行だけが残る。それも「処理済み」だった。

　白化件数が今日も増えた。ジンはBlancだから数字に入らない。入らなくても、ジンは今日まで生きていた。何年も、ダーク4番区で、施設の人間を見ていた。「気をつけろよ」と言い続けた。緑を見せたかった、と言った。「お前はいいやつだ」と言った。乾燥した芋を包んで差し出した。飯を準備した。朝食を持ってきた。全部、毎回、何でもない言葉と行動だった。

　誰にも記録されない。

　カインが記録している——そう思った瞬間、カインは少し立ち止まった。ジンのことを、カインは頭の中に持ち続けている。それが記録だった。形にならない記録だったが、確かにあった。忘れない限り、そこにあった人間は「いた」。それだけは今日、確かになった。

　ターミナルの画面が静かに更新された。今夜も誰かが消えた。誰かが数えた。数えている理由は、今日のカインには少し分かった気がした。

---

```
【日記の断片】

記録とは何のために存在するか。
「忘れないため」と言う人がいる。
「証拠のため」と言う人もいる。
私はそのどちらでもなく、「分かってほしいため」に書いている。
誰かに、いつか、分かってほしい。
```
