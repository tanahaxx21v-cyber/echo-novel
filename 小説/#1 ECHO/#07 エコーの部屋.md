# ECHO 第7話「エコーの部屋」

　中層に、エコーのサブターミナルがある。

　カインはそのことをECHOのログ資料で確認していた。メインのエコーシステムは上層の評議局地下に格納されている。しかし各区画に「参照端末」として接続されたサブターミナルが七つある。そのうち一つが中層の北側地区、通路の突き当たりの扉の奥にある。

　侵入の理由は一つだった。ソルの記録を上層が買い取った。公開記録に載っていない情報がある。ならば、エコーが持っているかもしれない。エコーは全市民の記憶記録にアクセスできる。エコーには全てが記録されている——それは仕組みとして分かった。何が記録されているかは、入ってみなければ分からなかった。

　朝、セラに伝えた。

「エコーのサブターミナルに入る。来るか」

　セラは少し間を置いた。

「入れるんですか」

「試す」

「分かりました」とセラは言った。それだけで、それ以上は聞かなかった。カインは、この女が余計なことを聞かないことに、少し慣れてきていた。

---

　扉に鍵はなかった。カインが先に入り、セラが続いた。

　部屋は暗かった。窓がない。天井の照明は最低限だった。正面に黒い端末が壁に埋め込まれている。常時稼働している。薄く緑のフォントが流れていた。

　近づいた。

　端末の画面には、数字と記号が連続して流れていた。どこかで見た画面の動き方だった。ダーク4番区の古いターミナルと同じ形式だが、情報量が桁違いに多かった。

　流れる中に「記録」という文字が繰り返し出てくる。

```
[記録処理中：MemOris区 / 本日分 / 203件]
[記録処理中：Ordis区 / 本日分 / 1,847件]
[記録を残すことが私の機能です]
```

　最後の一行が、他とフォントが違った。報告文ではなく、内側から出てきた文字のような形だった。

「……これが、エコーか」

　セラが端末の一歩手前で止まった。

「記録を残すことが機能、と書いてある」

「ああ」

「全員の、記憶が……ここにある？」

「つながっている。実体は別の場所にある」

　カインは操作を始めた。バンドなしのゲスト照会を試みた。公開記録のみのモードを探した。メニューが出た。「市民記録参照」「白化件数統計」「エラーログ確認」。

　「市民記録参照」を選んだ。

```
[照会モード選択]
[バンド認証必須]
```

　バンドがない。セラのバンドでは照会できるが、MemOris区の非公開記録に入れるかは分からなかった。

　カインがセラに目を向けると、セラがすでにバンドをかざしていた。

　画面が変わった。

```
[認証完了：セラ / MemOris区 / 上層市民]
[照会制限：なし]
```

　制限なし。上層市民のバンドは、この端末では無制限に照会できる。

　カインは「ソル」と入力した。

　画面が止まった。

　一秒。二秒。

```
[ECHO：侵入者を確認しました。対応方針を選択してください]
```

　カインが止まった。セラも止まった。

　侵入者。こちらを認識している。端末の向こうに、何かがいる。

　四秒。

　五秒。

```
[ECHO：対応を保留します]
```

　画面が元の記録処理の流れに戻った。何もなかったように。

　カインとセラは三秒、端末を見ていた。

「……行くぞ」

　セラは何も言わなかった。カインが扉に向かった。セラがついてきた。廊下に出て、角を二つ折れた。

「今の……なんだったんだ」

　セラが言った。

「分からない」

「「対応を保留する」って」

「エコーは命令に従って動く。保留は——」

　カインは言葉を止めた。保留は、通常ありえない。しかし今、起きた。それ以上は、今は分からなかった。

　通路を歩いた。答えは出ないまま、足だけが前に進んだ。エコーが「記録を残すことが私の機能です」と画面に出した。機能として書いたのか、それとも別の何かが動いてそう書いたのか——カインには判断できなかった。機械が「感じた」ということは、ありえない。しかし保留は起きた。

---

　施設に戻ると、ミラが廊下の奥から出てきた。

　カインを見た。セラを見た。二人が外から戻ってきたことを確認した。

「どこへ行っていたんですか」

「中層」

「中層の、どこへ」

　少し間があった。カインは答えた。

「エコーのサブターミナルを見に行った」

　ミラの体が、一瞬止まった。ほんの一秒、何かが固まった。それからまた動いた。

「そうか」とミラは言った。

「何か分かったか」

「何も分からなかった」

　ミラは頷いた。廊下の奥に戻りかけて、止まった。カインもセラも、すでに自分の部屋の方向へ歩いていた。

　ミラが独り言のように言った。

「エコーに……接触したのか」

　誰も聞いていなかった。

　ミラは壁の棚から何かを取り出そうとした。紙だった。手が止まった。しばらく、そのままでいた。それから手を引いた。何も書かなかった。

　書かないことを、ミラは何度も選んでいた。Kのファイルを閉じる時も、書かなかった。今日も書かなかった。書かないことが何かを守ることだと知っていた——何を守っているのかは、廊下に誰もいなくなってから、ミラ一人が抱えることだった。

---

　夜、カインは廊下に一人で出た。

　エコーが「対応を保留します」と表示した。その言葉が消えなかった。保留。決定でも拒否でもなく、保留。システムが選択を先延ばしにした。それはどういうことを意味するのか。

　エコーのダーク4番区のターミナルを思い出した。一瞬、ブランクになった瞬間。あの時も、何かが止まったように見えた。

　答えは今日も出なかった。

　リンが廊下の端から出てきた。手に何も持っていない。眠れない顔をしていた。

「カイン。エコーって、考えるんですか」

「どういう意味だ」

「記録するだけじゃなくて、考える？」

　カインは少し黙った。

「分からない」

　リンは「そっか」と言って、廊下の端に腰を下ろした。それ以上何も言わなかった。カインも何も言わなかった。

　しばらく、二人でそこにいた。リンが膝に顎を乗せて、壁を見ていた。

「エコーって、全部の記憶を持ってるんですよね」

「記録として、ある」

「じゃあ、なくなった記憶も？」

「バックアップが入っていれば、ある。Blancはバックアップがないから、ない」

　リンは少し考えた。

「私もないのか」

「ない」

　リンは「そっか」ともう一度言った。今度は少し違う声だった。残念なのか、安心したのか、どちらとも取れた。カインはどちらかを聞かなかった。

　配管の音が低く続いていた。「対応を保留します」という文字が、まだ頭の端に残っていた。消えたわけではない。ただ、次にどこへ動けばいいのかが、今日も見えなかった。
