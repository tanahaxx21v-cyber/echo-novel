# ECHO 第7話「エコーの部屋」

　評議局がソルの記憶を買い取った。その記録は、エコーの管理システムにある。

　中層の記録管理区画——公共端末の置かれた通路からさらに奥、一般立入禁止の表示がある場所。扉の前に立った。スキャン範囲に入った瞬間、機械の音が変わった。

```
[対象データなし]
[読み取りエラー / 障害コード：ERR-404]
[処理：通過許可（後日点検）]
```

　扉が開いた。

---

　内部は暗かった。

　通路の光は届かない。端末だけが等間隔に並んで、青白い光を放っていた。においがない。記憶マーケットと同じ、何かが取り除かれた空気だった。

　端末は全て稼働していた。画面を見ると、ログが流れていた。

```
[ECHO：本日のバックアップ処理：完了]
[ECHO：MemOris区記録同期：完了]
[ECHO：記録を残すことが私の機能だ]
[ECHO：処理件数：2,341件]
```

　どこかに「ソル」という記録が残っているか。カインは端末の一つに手を伸ばした。照会を試みた。

　その瞬間——

```
[ECHO：侵入者を確認しました。対応方針を選択してください]
```

　セラが息を止めた。

　カインは端末から手を離さなかった。

　五秒。

```
[ECHO：対応を保留します]
```

　また静かになった。

　セラが小さな声で言った。

「……今の、なんだったんですか」

　カインは端末の画面を見た。ログは再び流れていた。「対応を保留します」という表示はもうなかった。「保留」——「許可」でも「拒否」でも「警報」でも「記録」でもない。ただ保留した。なぜそんな選択肢があるのか。カインには分からなかった。

「出るぞ」

　セラがついてきた。「……ありがとうございます」と言った。何に対するかは分からなかった。カインは返事をしなかった。

---

　施設に戻ると、廊下でミラが出てきた。

　カインを見た。セラを見た。一瞬、何かを考えた。

「……エコーに、接触したのか」

　廊下には誰もいなかった。カインとセラに言ったのか、独り言だったのかは分からなかった。

　ミラは手元に何か小さなメモを持っていた。書き留めようとした。手が止まった。メモをポケットにしまった。書かない、という選択だった。

「夕飯、できてるから」

　それだけ言って、ミラは廊下の奥へ戻っていった。

　廊下の端でジンが壁に寄りかかっていた。

「エコーって、怖いのか」

「別に」

　ジンはしばらく考えた。「そうか、怖くないのか」と一人で言って、廊下の奥に戻った。

---

　夜、カインは端末の前を思い出した。

　「対応を保留する」という選択肢は、命令実行型AIの通常動作にない。

　なぜ。

　答えは出なかった。ただ「保留」という二文字が残った。
