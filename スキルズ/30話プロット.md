## 執筆者向け境界定義（稲垣B-2・B-3・香取④追記）

### 日記断片の位置づけ（稲垣B-3）
各話末尾の「日記の断片」は**読者への先行情報・伏線**として機能する設計である。
物語内でキャラクターが「白化の真実」を知るのは第23話だが、読者は日記断片を通じてより早い段階で情報の断片に触れる——これは意図的な設計。「日記断片に真実が書かれている＝キャラクターが第23話より前に知っていた」ではない。執筆者は日記断片と本編の「知る時点の差異」を混同しないこと。

### 第16話のソル情報開示レベル（稲垣B-2）
第16話でエコーのターミナルに「ソル / 記憶データ / 保管中」という表示が出る。これは**セラ（および読者）が「ソルの記憶データが存在する」と知る段階**であり、「ソルがエコーそのものの中にいる」という核心は第24話（ミラの告白）まで明かさない設計。
第16話の執筆では「記憶データとして保管されている事実」まで開示し、「なぜ・どのように・エコーとの関係」は第24話まで開示しないこと。この区別を明確に描写すること。

### 第17話の日記断片について（香取④）
第17話の日記断片「最初の記憶がない人間は——最初から、空っぽだった」は、カインが自分自身を客体化して書いた表現（研究者風カモフラージュの一部）である。読者は「書き手には最初の記憶がある→書き手はカインではない」と誤読する可能性があるが、これはミスリードとして意図された設計。第30話での開示時、読者は「カインは自分のことをあえてこう書いた（三人称的な自己観察として）」と理解する。執筆時に「なぜカインがこう書いたか」の動機（カモフラージュの徹底）が第30話の解説場面で読者に伝わるよう設計すること。

### 日記ミスリード誘導経路まとめ（香取A級対応）——読み返し時発見リスト

第30話で「日記の書き手がカインだった」と明かされた時、読者が「ああ、そういえば……」と振り返れる伏線の密度を確保するため、以下の話数に「読み返し時に機能するカイン特定伏線」が設計されている。

| 話 | 日記断片のキー表現 | 読み返し時の機能 |
|----|-----------------|----------------|
| 第1話 | 「真実は、公式記録の中に存在しない。だからこそ、私は書く」 | Blancとして「記録から存在しない」カインが書いた言葉として再解釈できる |
| 第3話 | 「壁は、それが「存在する」と信じる者にのみ機能する」 | フェールオープン発見話と同日の断片——カインの体験の直後として機能 |
| 第7話 | 「2376年の投票結果を、私は今も手元に持っている」 | 「今も手元に持っている」——カインが成人後にアーカイブで入手した情報として再解釈 |
| 第10話 | 「守るとは——消えないように、隣にいることだ」 | 第10話でセラを守った日に書いた断片。書き手の感情体験として一致 |
| 第14話 | 「遅すぎた気づきを——私は今も抱えている」 | ジンの死の話と同日。「今も」抱えているという現在形がカイン執筆者視点を示す |
| 第17話 | 「最初の記憶がない人間は——最初から、空っぽだった」 | カインが自分を三人称で書いたカモフラージュ（第17話断片の解説参照） |
| 第21話 | 「「自分とは何か」という問いに、記憶は答えられない」 | K-001として記憶を持たないカイン自身の問いとして再解釈 |
| 第27話 | 「「私」は役割だ。「俺」は人間だ」 | 「私」一人称で書きながら「俺」の意味を解説しているカイン自身の逆説 |

**執筆者向け注意：** 日記断片の文体（「私」一人称・研究者風格調）は本編のカインの話し方（「俺」短文断定）と完全に異なる。この文体差こそがミスリードの核心であり、かつ第30話で「カインが意図的にそう書いた」という腑落ちを支える構造。日記断片は「カインが書いた」という事実を忘れて研究者風に書き、本編のカインは「俺」で話す——この二重性を執筆全話を通じて維持すること。

## Arc 1「存在と侵入」（第1〜5話）

**Arc核：カインがフェールオープンを発見し、上層への道を開く**
**感情目標：「この世界の理不尽さ」の提示と、カインとセラの出会い**

---

### 第1話「それでも朝は来る」

**感情目標：** 白化の恐怖と日常の同時提示。読者を「この世界」に引き込む

**主要イベント：**
1. カインが朝、ダーク4番区を歩く
2. 白化した老人を目撃する
3. 施設に戻るとジンが朝食を持ってきている
4. ミラが「今日も全員そろっているか」を確認する
5. 夜、カインは一人で外に出る。エコーのターミナルの前に立つ
6. 「[ECHO：本日の白化発生件数：14件]」という表示を見る——ただ「見た」のではなく、「なぜ記録が存在するのか」「誰が管理しているのか」という問いを内側に持って見ている（香取B修正：受動的認識ではなく、「知りたい」という能動的欲求の最初の形として主要イベントに明記）
7. 日記の断片が一節、挿入される

**感情の種（新規追加）：**
- **白化の具体性：** 「昨日まで自分の名前を言えた老人が、今朝は名前を呼ばれても目が虚ろなまま止まっていた。誰かがいた、という感覚だけ残して、その誰かが誰だったかはもう分からなくなっていた」——これを一行で。恐怖の輪郭として
- **カイン×ジン（仕込み）：** ジンが朝食（乾燥した保存食）を差し出す。カインは受け取りながら何も言わない。ジンはそれでいいと知っているので何も言わない。この「何も言わない」二人のやりとりに、読者は二人の間の信頼を感じる
- **カインの能動的関心（香取①対応・B-6追記）：** エコーのターミナルの前に立つカインが「ここには全てが記録されている」と思うだけでなく、「なぜ記録が存在するのか」「誰が管理しているのか」という問いを一行で内側に持つ。「見た」という受動的な認識ではなく、「知りたい」という能動的欲求の最初の形として描く設計。これは第3話でフェールオープンを発見するための「情報への渇望」の芽として機能する。

**日記の断片：**
```
私はこの記録を、誰に読まれるためでもなく書き始めた。
真実は、公式記録の中に存在しない。
だからこそ、私は書く。
```
（文体：「私」一人称・研究者風・格調ある文体。読者は「研究者の日記だ」と思う）

**次話への引力：** エコーのターミナルの前でカインは「ここには全てが記録されている」と思う。しかし何も言わずに立ち去る。「何を探しているのか」という読者の疑問を残す。**【フック追記（香取①B対応）：** カインが立ち去る瞬間、ターミナルの「[ECHO：本日の白化発生件数：14件]」が一瞬「[ECHO：——]」に変わり、また「14件」に戻る。カインはその変化を見ていない。読者だけが見る小さな異変——「なぜエコーが一瞬ブランクになったのか」という謎を残す（第25話でエコーとソルの記憶が接触した際の処理割り込みの片鱗として機能するが、第1話では何も説明しない）】

### 第2話「落ちた星」

**感情目標：** セラとの出会い。「ソルを探す」という動機の提示。カインの「余計なもの」感

**主要イベント：**
1. 上層から転落してきた人間がいるという連絡がジンから届く
2. カインが確認に行くとセラが倒れている（メモリア装着・上品な服）
3. セラが意識を取り戻す。「私はセラ。ソルを探しています」
4. カインは「知らない。帰れ」と言う
5. セラは「帰れない。記憶を失ったので、帰る場所が分からない」と言う
6. カインは無言でセラを施設に連れて行く（理由は言わない）
7. オルトが「誰を待っていたんでしょうね、私は」と呟く

**感情の種（新規追加）：**
- **カイン×ジン（仕込み）：** 「あの女、どうするんだ」とジン。「まだ分からない」とカイン。「お前が決めろ。俺は干渉しない」と言って去るジン。「決める」という言葉の重さがあとで効く
- **ソルの積み上げ：** 「弟です。6年前に消えました。名前はソル」とセラ。「どんな子どもだったか」とカイン（珍しく質問する）。「……分からないんです。記憶がないので」とセラ。カインは黙る。「自分の弟を覚えていない」という切実さ
- **オルトの伏線：** 「誰を待っていたんでしょうね、私は。ずっと待っている気がするんですが、誰かは思い出せない」——第29話への仕込み

**日記の断片：**
```
被験体の観察を開始した初日のことを、私は今も覚えている。
その目には感情がなかった。生きているが、人間ではないような目だった。
しかし私は知っている。感情がないのではない。感情を持つことを、
誰かに許可されなかっただけだ。
```
（「被験体」という言葉——読者はK-001実験の研究者が書いていると思う。実はカインが意図的に書いた研究者風文体）

**次話への引力：** 「ソルはどこにいるのか」——読者の疑問が植え付けられる

### 第3話「境界線」

**感情目標：** フェールオープン発見の興奮。「Blancに無限の可能性がある」という逆説的な希望

**主要イベント：**
1. カインが中層へのゲートを試みる（セラの手がかりを求めて）
2. スキャンされる→「センサー故障」と判定→通過許可
3. カインが仕組みを理解する。「Blancは記録から消されているからこそ、記録を必要とするシステムを通過できる」
4. 中層の情報収集。「ソル・6年前失踪・記録なし」という情報を掴む
5. 帰還。セラに「ソルの手がかりはなかった。でも道は見つけた」と伝える

**感情の種（新規追加）：**
- **カイン×ジン（仕込み）：** 出発前、ジンが一言「気をつけろよ」と言う。カインは振り返らずに「分かった」とだけ言う。この「分かった」が珍しい——カインは普通「分かった」すら言わない
- **フェールオープンの体験：** カインが「なぜ通れた」を25年誰も知らなかった理由を考える。「下層には情報を交換する手段がない。上に上がった者は戻ってこなかった。だから誰も伝えられなかった」——これは一行だけでいい

**日記の断片：**
```
境界線とは何か。
私は長い間、それを「壁」だと思っていた。
しかしある日気づいた。
壁は、それが「存在する」と信じる者にのみ機能する。
```
（読者には「研究者の哲学的な記述」に見える）

**次話への引力：** 「ソルの手がかりが中層にある」——次の行動への動機

### 第4話「値段のついた記憶」

**感情目標：** 記憶売買システムの残酷さ。「記憶が商品」という世界観の体験

**主要イベント：**
1. セラと共に中層の記憶マーケットへ
2. 「子どもの感情記憶」が最高値で売られている場面
3. 「ソル・6歳・感情記憶」という商品リストをセラが見る（内容は非公開）
4. 「ソルの記憶は誰かが売った？」という疑問が浮かぶ
5. ミラが古い記録（「K」の文字が見えるファイル）を素早く閉じる場面（施設に帰ってから）

**感情の種（新規追加）：**
- **ソルの積み上げ：** セラが「子どもの感情記憶」の値段札を見て、一瞬立ち止まる。「ソルの記憶も……」とだけ言いかけて止まる。「ここにあるかもしれない」を言えない。カインは声をかけない。「言えないことを分かっている」という描写
- **ミラの仕込み：** 施設に帰った後、ミラが「どうだったか」と聞く。カインが「記憶が売れる。子どもの感情記憶が高かった」と報告する。ミラが「K」の文字が含まれる古いファイルを素早く閉じる——閉じた理由は言わない
- **カインのセラへの違和感・初出（草彅B-1修正）：** 記憶マーケットでセラを「連れてくるべきでなかったか」と一瞬考えるカイン——「なぜまだここにいるのか」という問いが最初に生まれる場面として1行描写すること。感情的関心ではなく「処理しきれていない存在」として認識している段階。この問いが第5話・第6話と続く違和感積み上げの初出となる（キャラクター設定書「感情の扉が開くまでの変化・第4〜6話：セラへの小さな違和感」の実装）。

**日記の断片：**
```
感情記憶が最も高値だった。
喜びと痛みは同じ価格がついた。
私はそれを聞いて、この世界が何を間違えたかを理解した。
感情とは売れるものではない。感情とは、経験の積み重ねだ。
それを取り出した瞬間、その人間は少し死ぬ。
```

**次話への引力：** 「ソルの記憶は記憶マーケットにあったのか？」という疑問が残る

### 第5話「ハイブの空気」

**感情目標：** 上層MemOrisの世界の「豊かさと空虚さ」の対比。セラの異変（メモリアへの違和感）

**主要イベント：**
1. カインとセラが上層（ハイブ）へ潜入
2. MemOrisの豊かさを目の当たりにする
3. セラがメモリアを持つ市民たちを見て「自分のメモリアが微妙に違う」と感じる
4. レイドの部下がセラを確認しようとする——かろうじて逃げる
5. 帰路でレイドがセラを「見つけた」場面——「上層に戻るべきだ、セラ様」と言う。命令ではなく忠告として。声のトーンが一瞬変わる

**感情の種（新規追加）：**
- **カイン×ジン（仕込み）：** カインが帰ると、ジンが施設の入口付近で待っていた。「戻ったか」とだけ言ってジンは自分の作業に戻る。これだけ——しかし「待っていた」という事実が残る
- **オルト（草彅B-1中間仕込み⑤）：** 施設の入口付近、ジンが待っていた場所から少し離れた椅子に、オルトが座っている。ジンとは別の方向を見ている。「ジン、またここで待ってるの？」と誰かに聞かれたジンが「そういうお前も待ってるだろ」とオルトに言う。オルトは「ああ、俺はいつでも待ってる」とだけ言う——この「いつでも待つ」という姿勢が自然に読者の記憶に刻まれる（第29話回収への布石）
- **レイドの人間性（仕込み）：** レイドが「上層に戻るべきだ。あなたの場所はここではない」とセラに言う場面で、レイドの声のトーンが「命令」ではなく「忠告」になる一瞬がある。「なぜ忠告を？」という疑問が残る
- **レイドの「守りたかったもの」の片鱗（B-5追記：香取⑤対応）：** この「忠告」の一瞬、レイドの視線が「今のセラを守ること」ではなく「別の何か」に向かっているように描写する——それが「何か」は第27話まで明かさない。「評議局を守ろうとしてきたはずなのに、その手段として選んだものが正しかったかどうか」という問いをレイドが無意識に抱えている状態を一行だけ読者に伝える設計。第27話の「俺は……間違えたのかもしれない」との対比として機能させること。

### 第14話「ジンの席」

**感情目標：** 最大の感情的山場。ジンの死。カインの「感情の扉」が開く

**主要イベント：**
1. 評議局がBlancの施設を強制捜索する
2. ジンが「全員を逃がす」ために残る
3. カインは「待て、俺が」と言うが、ジンに「行け」と言われる

**感情の種（核心）：**
- **第14話がなぜ機能するか（設計根拠）：** 第1〜13話でジンが毎回一言二言だけカインと交わした「何でもない言葉」が全て積み重なっている。「気をつけろよ」「よかったな」「緑を見せたかった」「お前はいいやつだ」——これらが全て「ジンがカインを大切にしていた証拠」として読者の中に溜まっている。だから「転落死」という三文字が刺さる
- **第14話の核心（B-1追記）：** カインが評議局の支局へ一人で向かうという行動そのものが感情の証明。泣かない・怒らない——それでも行動する。この行動の根底にあるのは「ジンへの喪失感・義務感・怒りが一体化した何か」。カインはこれに名前をつけない。つけられない。しかし読者にはそれが感情だと分かる。これが第14話の核心。
- **ジン×セラの積み上げ：** ジンの死の直後、セラがカインの横に黙って立っている。「あなたも誰かを失ったことが……ある？」とセラ。「あるかもしれない」とカイン——初めての「喪失の可能性」を認める言葉。カインがここまで「かもしれない」を使ったのは第9話以来

```

持っていた時には気づかない。

その気づきが、遅すぎることがある。
遅すぎた気づきを——私は今も抱えている。
```
（読者は「研究者が何かを失った記録」と思う）

**次話への引力：** 「カインは一人で何をしに行くのか」

### 第15話「処理済み」

**日記の断片：**

「忘れないため」と言う人がいる。
「証拠のため」と言う人もいる。
