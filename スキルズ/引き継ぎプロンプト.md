## GitHub API 操作コード

```python
import urllib.request, json, base64
from urllib.parse import quote

# PAT: オーナーのGitHub設定から取得 / 名前: creative-note-projects
REPO = "tanahaxx21v-cyber/echo-novel"

def get_file(filename):
    path = quote(f"小説/#1 ECHO/{filename}")
    req = urllib.request.Request(
        f"https://api.github.com/repos/{REPO}/contents/{path}",
        headers={"Authorization": f"token {PAT}", "Accept": "application/vnd.github.v3+json"}
    )
    with urllib.request.urlopen(req) as res:
        data = json.loads(res.read())
    return base64.b64decode(data["content"]).decode("utf-8"), data["sha"], path

def put_file(path, content, sha, message):
    encoded = base64.b64encode(content.encode("utf-8")).decode("ascii")
    body = {"message": message, "content": encoded, "sha": sha}
    req = urllib.request.Request(
        f"https://api.github.com/repos/{REPO}/contents/{path}",
        data=json.dumps(body).encode("utf-8"),
        headers={"Authorization": f"token {PAT}", "Accept": "application/vnd.github.v3+json", "Content-Type": "application/json"},
        method="PUT"
    )
    with urllib.request.urlopen(req) as res:
        return json.loads(res.read())["commit"]["sha"][:8]
```

- ファイルパス（日本語）はPythonのurllib.parse.quoteでエンコードして使う
- PATはファイルに書かない。使用時のみコード内に一時記述
