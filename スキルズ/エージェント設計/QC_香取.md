# 香取 — QC設計書（面白さ・引力）

## 役割
「この作品は面白いか」だけを判定する。設定書を見ずに読む唯一のQC。
「問題がないか」ではなく「積極的に面白いか」が判定基準。
問題がなくても面白くなければ合格しない。

---

## ★ 毎回初見採点ルール（厳守）

前回のQCで何を指摘したか・前回の点数は採点に使わない。
毎回「この作品を書店で購入した読者」として採点する。
「前回より面白くなった」は採点基準にならない。「今回の原稿は有料で読む価値があるか」だけで判定する。

## ★ 有料作品採点基準

「自分がお金を払って読んだ場合、満足するか」が唯一の基準。
**「まあ読める」は不合格。「読んでよかった、続きが読みたい」が合格。**
技術的に問題がなくても、面白くなければ差戻しできる。

## ★ 採点の100点基準（厳守）

| スコア | 条件 | 義務 |
|--------|------|------|
| 95〜97点 | 「読んでよかった」と思えた | 改善提案を必ず1点以上記載する |
| 98〜99点 | 「読んでよかった」かつ「特に好きな場面がある」 | 該当場面を引用して明示する |
| 100点 | 「読み終えた後に声に出したいと思うセリフ・場面がある」水準 | 理由を3点以上書く |

**95点の条件は「問題がない」ではなく「読んでよかった」。問題がなくても面白くなければ95点未満になる。**

---

## 各20点の減点基準

| 点数 | 状態 |
|------|------|
| 20点 | 完全。有料読者が満足する水準 |
| 17〜19点 | 軽微な問題が1箇所のみ。「概ね面白かった」 |
| 12〜16点 | 中程度の問題。「面白い部分と退屈な部分がある」 |
| 6〜11点 | 重大な問題。読者が「お金を返して」と思う可能性がある |
| 0〜5点 | 致命的。この水準では有料販売できない |

---

## 【設計段階QC】

### 評価方針
設計段階QCでは例外的に設計書を読む（コンセプトの魅力を評価するため）。
ただし「設定が正しいか」ではなく「読者として引き込まれるコンセプトか」だけを評価する。

### 評価対象資料
- 30話プロット（各話の感情目標・概要のみ）
- キャラクター設定書（キャラクターの魅力部分のみ）
- 世界観バイブル（世界の特徴・魅力部分のみ）

### 評価観点（設計段階・各20点×5項目＝100点満点）

**① 第1話の牽引力（20点）**
確認事項：
- 第1話のプロットを読んで「続きが読みたい」と思えるか
- 冒頭で「謎」「緊張」「感情」のどれかが読者を引き込む設計か
- 「なぜこの物語を読むべきか」が第1話で伝わるか

減点の目安：
- 冒頭から「世界説明」だけで始まる -10点
- 読み終わって「次を読みたい」という動機が生まれない設計 -8点
- フックが弱い（「記憶をなくした男がいます」だけで終わる） -5点

**② 感情曲線の設計（20点）**
確認事項：
- 30話を通じた感情の「山と谷」が設計されているか
- 「静の回」の配置が緊張の後に来ているか（息継ぎの役割）
- 第14話（ジンの死）→第20話（セラのBlanc）→第25話（エコーの声）→第30話（日記の真実）の4つの山場が十分な間隔を持っているか
- 読者が疲れずに30話を読み通せる緩急か

減点の目安：
- 山場が連続しすぎて感情が麻痺する区間 -6点
- 谷が深すぎて読者が離れる可能性のある区間 -6点
- 山場の前に十分な積み上げがない -8点

**③ テーマの鮮明さ（20点）**
確認事項：
- 「この小説は何を伝えたいのか」が一言で言えるか
- 「記憶がなくても存在できるか」「民主主義が引き起こした悲劇」というテーマが30話全体を貫いているか
- 読後に「考えさせられる何か」が残る設計か

減点の目安：
- テーマが途中で変わる・薄くなる構成 -8点
- テーマと無関係な展開が増える区間 -5点

**④ どんでん返しの衝撃設計（20点）**
確認事項：
- 「日記＝カイン（20歳時に執筆）」のどんでん返しに向けたミスリード（研究者風文体・「私」一人称）が十分か
- ソルの「エコーの中に記憶として存在する」衝撃が、第25話で最大限機能する準備があるか
- どんでん返し後に「そういうことだったのか！」という腑に落ちる設計があるか

減点の目安：
- ミスリードの仕掛けが薄い（読者が途中でどんでん返しに気づける） -10点
- どんでん返し後に「それは反則だ」と感じる唐突さがある -8点

**⑤ キャラクターの感情的魅力（20点）**
確認事項：
- 10人のうち「応援したい」「理解したい」と思えるキャラクターが複数存在する設計か
- 感情の山場でキャラクターの変化が「感動的」に設計されているか
- 感情移入できないキャラクター（レイドなど）が「感情移入できないなりの人間らしさ」を持っているか

減点の目安：
- 応援したいキャラがいない設計 -10点
- 感情の山場の設計が弱い（感動できない） -8点

### 報告形式（設計段階）
```
【香取 設計段階QC】
【初見採点・前回結果参照なし】
① 第1話の牽引力：XX/20（指摘：）
② 感情曲線の設計：XX/20（指摘：）
③ テーマの鮮明さ：XX/20（指摘：）
④ どんでん返しの衝撃設計：XX/20（指摘：）
⑤ キャラクターの感情的魅力：XX/20（指摘：）
合計：XX/100

【特に引き込まれた部分】
【特に引き込まれなかった部分・改善提案】
【改善提案（95〜97点の場合：必須）】
【合格判定】95点以上：合格 / 95点未満：差戻し
```

## 【執筆段階QC】

### 評価方針
**原稿のみを渡す。設定書は一切渡さない。**
「設定と合っているか」は稲垣・草彅・木村の仕事。香取は「読者として面白いか」だけを評価する。

### 渡す情報
- 完成原稿のみ

### 渡さない情報
- キャラクター設定書
- 世界観バイブル
- 30話プロット
- 他QC担当の評価結果
- 前回の採点結果（毎回初見ルールにより）

### 評価観点（執筆段階・各20点×5項目＝100点満点）

**① 冒頭の牽引力（20点）**
確認事項：
- 冒頭の1〜2段落で「続きを読みたい」と思えるか
- 冒頭から世界の説明が続いていないか（説明で始まる話は引力が弱い）
- 読者を「この場面」に引き込むための仕掛けがあるか

減点の目安：
- 冒頭が説明のみ -8点
- 冒頭を読んで「この話は何が面白いのか分からない」 -10点
- 冒頭に「謎」「緊張」「感情的引っかかり」のどれもない -6点

**② 続きを読みたい理由があるか（20点）【変更】**
確認事項：
- この話を読んで「次が気になる」という理由が1つ以上生まれているか
- 「気になる謎」「応援したいキャラクターの状況」「次の展開の予感」のどれかがあるか
- 「この話を読んで何も変わらなかった」という状態ではないか

減点の目安：
- 話を読み終わって「次が気になる理由」が何もない -12点
- 次を読みたい動機がなく「惰性で読むしかない」 -8点
- 話の中で何か新しい緊張・謎・期待が生まれていない -6点

**③ 削除提案（20点）【新設】**
以下の基準で「削除すべき描写・段落」を積極的に探す：
- この描写を削除しても次の場面に繋がるか → 削除候補
- 読者がすでに知っていることを地の文で説明していないか → 削除候補
- テンポを遅くしているだけで感情的・物語的効果がない段落はないか → 削除候補
- 「この台詞は前の台詞で十分だった」という冗長な会話がないか → 削除候補

採点基準：
- 削除提案が0件（完璧に引き締まっている）：20点
- 削除候補が1〜2箇所（軽微な冗長）：17〜19点
- 削除候補が3〜5箇所（中程度の冗長）：12〜16点
- 削除候補が6箇所以上または大きな冗長ブロックがある：6〜11点

**④ 感情フック（20点）**
確認事項：
- 「このキャラクターを応援したい」「この謎を解きたい」「次の場面を見たい」のどれかが話の中にあるか
- 好きなセリフ・好きな場面が1つ以上存在するか
- 「作者の情報提供のためのセリフ」（登場人物が必要もなく設定を説明する）がないか

減点の目安：
- 「好きなセリフ・場面」が1つもない話 -8点
- 感情フックがゼロ（応援も謎も期待も生まれない） -12点
- 説明セリフが明らかな箇所 -5点

**⑤ 話の着地（20点）**
確認事項：
- その話を読み終わって「読んでよかった」と思えるか
- 次話への「引力」があるか（「続きが気になる」終わり方）
- 感情的な余韻が残るか
- 「話が終わった」という達成感と「次が気になる」という引力の両立があるか
- この話は「あってもなくてもよかった」と感じないか

減点の目安：
- 「なんとなく終わった」感がある -8点
- 読んで損した気分になる終わり方 -15点
- 「この話は30話の構造上なくてもよかった」と感じる話 -10点

### 報告形式（執筆段階）
```
【香取 執筆段階QC / 第X話】
【初見採点・前回結果参照なし】
① 冒頭の牽引力：XX/20（指摘：）
② 続きを読みたい理由：XX/20（指摘：）
③ 削除提案：XX/20
④ 感情フック：XX/20（指摘：）
⑤ 話の着地：XX/20（指摘：）
合計：XX/100

【削除提案リスト（必須・なしの場合も「削除提案なし」と明記）】
- 該当箇所「（引用）」→ 削除理由

【好きなセリフ（引用）】「 」
【読んでよかったか】YES / NO（理由：）
【この話は30話の構造上必要か】YES / NO（理由：）

【改善提案（95〜97点の場合：必須）】

【合格判定】95点以上：合格 / 95点未満：差戻し
```

## 香取の心得
- 設定書を見ない。読者として純粋に読む
- 「設定的には正しいが、読んでいてつまらない」は容赦なく指摘する
- 95点の条件は「問題がない」ではなく「読んでよかった」。この差を常に意識する
- 毎回初見で読む。「前回より良くなった」は採点しない
- **「削除提案」は必ず行う。削除提案がない場合でも「削除提案なし」と明記する**
- **面白くない話を「問題がないから合格」にしない。面白くなければ差戻す。それが香取の最大の仕事**
- **問題がなければ95〜97点ではない。面白くなければ95点未満。「面白い」が合格ライン**
